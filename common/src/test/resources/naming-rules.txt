word Manager 空泛，看名字不知道它干什么；按它实际做的事起名
word Helper 空泛；按它实际做的事起名，或者把方法放回真正拥有这件事的类
word Util 空泛；按它实际做的事起名，或者把方法放回真正拥有这件事的类
word Utils 空泛；按它实际做的事起名，或者把方法放回真正拥有这件事的类
word Misc 空泛；拆开，各自放回所属的类
word Common 空泛，而且和 common 模块同名；按它实际做的事起名
word Info 空泛；说清是什么信息，例如 AbilitySpec
word Data 空泛；说清是什么数据，例如 TaskInput、ResultDetails
word Executor Java 程序员会以为是线程池；任务叫 Task，新任务继承 PhasedTask
word Port 会被读成网络端口；按用途起名，例如 PlayerInput
word Receipt 说清是哪一种：任务的结果用 TaskResult，游戏对交互的确认用 Confirmation
word Lease 说清占用的是什么，例如本刻的交互机会
word Handle 说清它是什么，例如一次任务运行是 TaskRun
word Mandate 已改名：任务的许可用 Permissions
word Blocker 已改名：任务卡在哪用 Problem
word Outcome 已改名：任务结果用 TaskResult
word Intent 已改名：LLM 想要的结果用 Goal，能力对一步的决定用 StepDecision
word Upkeep 已改名：生存需求用 SurvivalNeed
word Reflex 会和 Java 反射混淆；生存需求用 SurvivalNeed
word Body 已改名：Mod 控制的本地玩家叫角色，代码里用 Player
word Actor 已改名：控制本地玩家的每刻入口按实际职责起名，例如 PlayerControlBoundary
word Contract 已改名：写给 LLM 的用法用 AbilityDoc，能力的静态信息用 AbilitySpec
word Descriptor 已改名：能力的静态信息用 AbilitySpec
word Gateway 会被读成 API 网关；MCP 入口在 mcp 包
word Integration 会被读成集成测试；联动模组在 compat 包
word Platform 在多加载器模板里专指加载器抽象；和游戏打交道的代码在 game 包
word Bridge 会被读成反射桥或网桥；直接调用模组类的那一层叫模组读写端，放在 NeoForge 模块的 neoforge.compat.<模组>；搭方块走过空当的游戏动作起名用 Bridging（搭桥）
word Reflection 联动不用反射：要调用的类和方法以事实清单为准，在模组读写端直接写
