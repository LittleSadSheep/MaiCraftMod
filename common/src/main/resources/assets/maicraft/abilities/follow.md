# 跟随（maicraft:follow）

跟着一位玩家或一个实体，保持几格距离：它走就跟，它停就停。跟随是常驻的，不会自己结束；要停下用 task 取消。目标消失或路走不通会结束并说明原因。跟随不包含保护它、帮它打架或跨维度找回。

## 怎么用

- 目标必填：`player`（一位玩家的名字）或 `seen`（先 `observe` 拿观察编号 e#）。
- `distance` 是保持的距离，单位格（2..16，默认 3）。走出设定值 +2 格才起步，回到设定值内就停，不会在临界距离一步一停。
- 编号被重用给了别的东西会判目标丢失，不会跟着新实体走。
- 跟不过去时以 UNREACHABLE 结束并说明允许改哪些方块就能过去；跟随默认不改地形，要不要开路由 `permissions.change_blocks` 表达。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `targetId` | 跟的是谁（类型与实体编号） |
| `keptDistance` | 结束时与目标的距离 |
| `lastDirection` | 最后看到目标在哪个方位 |

常见问题：`TARGET_GONE`（目标下线、走远或死亡）、`UNREACHABLE`（路走不通）、`NOT_FOUND`（观察编号对不上）。
