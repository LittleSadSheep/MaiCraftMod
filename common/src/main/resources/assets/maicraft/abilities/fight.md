# 打击（maicraft:fight）

打指定的目标，或清掉附近一片区域的敌对生物。先评估打不打得过：打不过会直接说差什么，不会白白送死。打谁、怎么打由 Mod 现场判断：够得着按双方身板算，冷却时退到对方够不着的地方等，有弓先射远的，对面举盾换斧，点着的苦力怕先躲。打不过或血见底就往没怪的方向撤，甩开了才停，撤离了不冒充打赢。击败后就地捡一下掉落物，捡不到也会如实说明。玩家、别人的宠物、有名字的动物不在清扫范围内；要点名打它们需要放开许可。

## 怎么用

- 想打某一只：先 `observe` 拿到它的观察编号（e#），把编号当目标点名。点名本身就是对它的许可；但有名有主的生物（有名字、驯服、拴着、圈着）和玩家点了名也要再确认一次：这次任务的 `fight` 开到 `any` 才动手，否则以 `NEED_APPROVAL` 结束并说清。
- 想清一片：省略目标，给 `radius`（默认 32 格）；清的是开打那一刻范围内看得见的这一批，途中真打了角色的怪一并处理。之后新刷出来的、墙后与地下看不见的不追，这一批打完、身边也没有在打我的就收手；要接着清就再下一次。`entity` 可以只清某一种，`count` 限制最多几只。没惹毛的中立生物（僵尸猪灵、末影人）不算敌对：清一片时不打，自卫也不主动去打，打一只僵尸猪灵会招来一群；它们惹毛了正在进攻、或真打了角色才还手。
- 近身走位：离目标落在"我够得着它、它够不着我"的那条缝里，同时离开别的追兵够得着的地方；身后是墙往侧面挪，被两边夹住往开口退；冷却中退到它够不着外、举着盾等；够得着就挥，退着也挥；头顶有空时充能过半就起跳、往下落时砍（暴击），起跳时就看着出手的那一点；落地时攻击条满、准星在它身上就站着直接砍，连着两跳一刀没砍出去就站着砍一阵。远处、隔墙的交给寻路，路上绕开怪群。
- 火球：恶魂火球这类能打回去的投射物冲着角色飞来时，站定盯着它，飞进够得着的地方就挥一下，顺着视线打回去（正对着恶魂飞回去，一下能炸死它）；打回去、它掉头或飞过去了就接着原来的打法。
- 苦力怕：点着引信、在波及范围里（7 格熄火距离与爆炸范围取大的，闪电劈过的 12 格）就当刻背离它疾跑，出了范围站住等它熄；没点引信的守在 3 格点火距离外砍，有弓先射；血不到一半又射不了就不凑上去砍，先避开它；它不在眼前同一层平地上（隔着坑、差着高、要绕路搭桥）就不寻路凑过去，守在点火距离外等它走过来。
- 身上有弓和箭、或有弩时会射（末影人除外：它会闪开箭，只近身打）：没有近战武器、对手是苦力怕、走不到它跟前，或离得比 7 格远就用弓，贴近到 4.5 格以内才换回近战；拉弓时离对手 6～10 格（它冲过来越快留得越多），离别的怪都至少 5 格，弓拉满、对准算出的弹道才放。连着两箭射不出去就改回近战。
- 武器按物品是什么认：剑、斧、重锤、三叉戟与模组的近战武器里挑每秒伤害最高的，对手举盾时用斧；没有剑斧时抄起手边一下伤害三点以上的工具（石镐以上的镐、铲、模组工具）打，不当空手见怪就跑。武器在主背包时，走过去的路上开背包把它换进快捷栏的空格（或放零碎的格）再按数字键选中，不挤掉手里的镐，以后打架按数字键就切过去；换武器开始了就换完。
- 点名打玩家（`fight` 许可开到 `any`）按出刀节拍走位：冷却好了凑进去打，没好就退到对方够不着的地方等；对方还手会接着打，打完收手。途中被别的、没点名的玩家打不会自动还手。
- 打不过（血见底、空手对面会还手）就撤：背离所有追兵、挑四十格外能站的落点放下盾疾跑，追兵只是跟在后面不停下，真被追上（它够得着我了）才面朝它退着还手，四十格内没有这次的追兵才算甩开（比僵尸盯人的 35 格远），撤离以失败收场——目标没死就是没打赢。连着三次走不通就背水一战；白天身上有废料、没有在射的，会就地垫高三格站在柱顶上打。
- 点名目标走不到跟前又射不到（隔着悬崖、水或墙），以 `UNREACHABLE` 收场并写明是哪只，不站着空转。
- 打完先回到最后一只倒下的地方，捡这一仗新冒出来的掉落（开打前就躺在地上的不碰）；收没收进包按服务器的拾取包认，捡不到的写进结果，不影响击败判定。
- 夜里撤不掉又打不过：这一仗停下（`DANGER`），交给自保挖坑把自己封起来熬到天亮。

## 打末影龙

点名末影龙（`observe` 拿到它的 e#），或者在末地不点名、龙在场时下 `fight`（`entity` 不给或给 `minecraft:ender_dragon`），就按龙的打法来；`radius` 内这一批别的敌对生物照常清。

- 开打前查装备：剑斧和弓都没有、或还有末影水晶却没有弓和箭（弩、联动远程武器也算），以 `NEED_ITEM` 结束并写明缺什么、水晶在哪。只有弓也打，但趴着的龙箭射不动，只能等它飞起来射。血低不拒战，先退开回血。
- 先射水晶：正连着光束给龙回血的那颗先射（打掉它龙自己掉 10 点血），其余近的先；站在爆炸范围外（离水晶 13 格以上、48 格以内）射得到的地方射，站上去射不到就换个站位。铁栏笼里射不进去、附近找不到站位的放弃并写明；要不要搭上去拆一根铁栏由你定（`build` 搭到笼边、`gather` 拆一根，再下 `fight`）。爆炸范围里有别的玩家、有主的生物不射；有末影人先等它走开，最多十秒。
- 躲：站进龙息（龙喷的、龙火球落地的紫色云）当刻跑出去；龙冲过来、两秒内会从身边 12 格内扫过，就横着跑开它的航线，来不及又拿着盾就面朝它举盾；龙火球会落到身边就跑开。走位、寻路都绕开龙息，不往岛边去。
- 龙趴到出口门上就去砍龙头（打龙头是全额伤害，打身子只有四分之一），不贴着龙头、龙脖子站（碰到也挨撞）；它吼完要喷之前先退出龙头前面，喷完再上。龙飞着时有弓、32 格内看得见就射；不然在出口门旁 8～14 格等它落。
- 末影人：不打没惹毛的；迈步、站着等的时候镜头一对上末影人的眼睛就压低看脚前，出手、放箭前视线上站着末影人就挪一步换个角度；惹毛了的近身打，打完接着打龙。头上戴着雕刻南瓜就不用躲。
- 血到 12 点（6 颗心）退到离出口门 20～30 格的地方站着，吃饭这项生存需求趁这个空当吃东西回血，回到 18 点或满血再回去；一分钟血一点没涨就收场（身上没吃的是 `NEED_ITEM`，有吃的是 `DANGER`）。
- 看到龙的死亡动画就算打赢：走到出口门边（门洞外）等它消失、门亮起来，顺便收经验，最多等二十秒；只看到龙不见了（走远、卸载）不算，记进 `lostTrack`。门亮以后不往门洞里走。
- 打到一半箭用完了而水晶还在，以 `NEED_ITEM` 结束；连着五分钟龙一次都没趴下、也没射中什么，以 `STUCK` 结束，写明最后看到龙在干什么、还剩几颗水晶。
- 进末地、备装备（剑、弓箭、甲、食物、南瓜头）、龙蛋、回主世界都要你来安排；结果里写出口门在哪、亮没亮。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `defeated` | 确认击败的目标（有死亡证据才算） |
| `lostTrack` | 点名目标在确认击败前就不见了（走远或被别的东西打死），不算击败；有跟丢的时任务为 partial（打掉了一部分）或 failed（一个都没确认），问题种类 `TARGET_GONE` |
| `fled` | 是否以撤离收场（此时任务为 failed，目标没死） |
| `retreat` | 撤离收场时为什么撤（血快见底、手上没有武器……） |
| `threatVerdict` | 开打前的威胁评估结论：winnable / risky / outmatched |
| `weapon` | 实际拿着打的那件 |
| `hits` | 确认打中的下数（近战，服务器确认了才算） |
| `shots` | 射出去几箭（弓、弩、联动远程武器；箭中没中服务器不单独回话，不算进 `hits`） |
| `reachIssue` | 点名目标里走不到跟前、也射不到的 |
| `lootGained` | 拾荒捡到的物品 |
| `dragon` | 打末影龙时才有，见下表 |

打末影龙时的 `dragon`：

| 字段 | 含义 |
| --- | --- |
| `crystalsDestroyed` | 确认是角色射掉的水晶数（射过、水晶在加载着的区块里消失才算） |
| `crystalsLeft` | 没打掉的水晶：在哪、为什么（还没打掉、铁栏笼挡着、附近找不到射得到的站位、看不到了），以及看不见水晶时龙还在长血 |
| `crystalsGoneOtherwise` | 不是角色射掉却没了的水晶数（别人打掉、被别的爆炸炸掉） |
| `health` | 最后看到的龙血量与上限 |
| `defeat` | 龙死的证据：看到了死亡动画、死亡动画后龙消失了、出口门亮了，有几样写几样 |
| `exitPortal` | 出口门的坐标与亮没亮 |
| `experience` | 这一仗得到的经验（等级与点数） |
| `rests` | 退开回血了几次 |
| `dodges` | 躲开龙息（`breath`）、冲撞（`charge`）、龙火球（`fireball`）各几次 |

常见问题：`DANGER`（打不过或撤离）、`NOT_FOUND`（观察编号对不上）、`TARGET_GONE`（点名目标打到一半不见了）、`UNREACHABLE`（点名目标走不到也射不到）、`NEED_APPROVAL`（要点名打有主的或玩家）、`NEED_ITEM`（打龙缺武器、缺弓箭，回血回不来又没吃的）、`STUCK`（打龙五分钟没动静）。战斗被生存需求打断再回来，进度不丢。

被没点名的玩家打（不在 `fight` 里也一样）：角色只退到他够不着的地方、举着盾，不还手；他停手后主任务暂停，事件里写明是谁，等你决定——要还手就用 `fight` 点名他，不理就让主任务继续。实例配置里的自家人打角色只发事件，不停工。
