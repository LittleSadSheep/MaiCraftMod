# 打击（maicraft:fight）

打指定的目标，或清掉附近一片区域的敌对生物。先评估打不打得过：打不过会直接说差什么，不会白白送死。打得过就上，武器自己挑（已上弦的弩 > 有箭的弓 > 剑或斧 > 空手），血见底会先撤离，撤离了不冒充打赢。击败后就地捡一下掉落物，捡不到也会如实说明。玩家、别人的宠物、有名字的动物不在清扫范围内；要点名打它们需要放开许可。

## 怎么用

- 想打某一只：先 `observe` 拿到它的观察编号（e#），把编号当目标点名。点名本身就是对它的许可；但有名有主的生物即使点了名也会先向你确认。
- 想清一片：省略目标，给 `radius`（默认 32 格）；清的是开打那一刻范围内看得见的这一批，途中冲着角色来的一并处理，按威胁排序——点着引信的苦力怕最优先，结果里写明处理了哪几只。之后新刷出来的、墙后与地下看不见的不追，这一批打完、身边也没有在打我的就收手；要接着清就再下一次。`entity` 可以只清某一种，`count` 限制最多几只。
- 打不过会以失败结束并说明差在哪（血、武器、数量）与怎样能继续；血量跌破拒战线会先撤离，甩开 32 格内所有追兵，但撤离以失败收场——目标没死就是没打赢。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `defeated` | 确认击败的目标（有死亡证据才算） |
| `lostTrack` | 点名目标在确认击败前就不见了（走远或被别的东西打死），不算击败；有跟丢的时任务为 partial（打掉了一部分）或 failed（一个都没确认），问题种类 `TARGET_GONE` |
| `fled` | 是否以撤离收场（此时任务为 failed，目标没死） |
| `threatVerdict` | 开打前的威胁评估结论：winnable / risky / outmatched |
| `weaponUsed` | 实际用的武器 |
| `lootGained` | 拾荒捡到的物品 |

常见问题：`DANGER`（打不过或撤离）、`NOT_FOUND`（观察编号对不上）、`TARGET_GONE`（点名目标打到一半不见了）、`NEED_APPROVAL`（要点名打有主的或玩家）。战斗被生存需求打断再回来，进度不丢。
