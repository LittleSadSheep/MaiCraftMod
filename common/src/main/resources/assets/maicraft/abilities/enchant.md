# 附魔（maicraft:enchant）

在附魔台给一件东西附魔。item 点名附魔哪件（身上没有会先去拿一件），tier 选三档报价里的第几档——第 n 档消耗 n 个经验等级和 n 个青金石，各档另有等级门槛（最高三十级，和旁边的书架数有关），等级不够会写清差多少。附出什么由游戏随机决定，结果列出实际附上的全部条目和等级；一件东西在台子上只有一次机会，不会拆掉重来碰运气。target 可以点名用哪个附魔台，不给就在附近找最近的一个；附近没有台子时如实说明，不会就地造一个。铁砧不支持。缺青金石或缺要附的东西，会先在身上和记得的箱子里找，要下矿才够就如实交代。

## 怎么用

- `item` 必填：附魔哪件，物品 ID 或 # 标签。已附魔的（含附魔书本身）台子不收第二次。
- `tier`：1..3，默认 1。
- `radius`：不给 target 时找台子的范围，格；只找已加载的地方，一次最多扫约 128 格，再远先 travel 过去。
- target：`seen`（b#）/ `position` / `landmark` 点名用哪张台子。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `offers` | 冻结的三档报价：门槛等级、实扣等级、青金石数、附魔线索 |
| `tier` | 这次用的档位 |
| `enchantments` | 实际附上的条目与等级（只有按钮确认后才给） |
| `levels_spent` / `lapis_spent` | 实际扣掉的等级与青金石 |

changes 里 `item_consumed` 记原物一件与用掉的青金石，`item_gained` 记成品。按钮按了却没能确认结果的，记进 unconfirmed，不会重发第二次。
