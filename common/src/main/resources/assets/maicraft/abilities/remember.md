# remember — 记住或忘掉一个地点，或圈一块玩家地盘

让角色按名字记住一个位置（"这是家""那是矿洞口"），把以某处为中心的一片圈成玩家地盘（"这一片是我的基地，别动"），或者忘掉一个记过的名字。只改角色的世界记忆，不移动角色、不读地形、不核实那里能不能站人——这些交给真正去那里的能力。执行是当场完成的：`execute` 直接返回结果，不成为主任务，也不打断手上正在做的事；放进 `sequence` 时，按顺序轮到它才记。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `name` | ✅ | 地点或地盘的名字；首尾空白去掉后原样比较，不改大小写 |
| `operation` | | `remember` 记住地点（默认，同名覆盖）/ `region` 以目标为中心圈一块玩家地盘 / `forget` 忘掉同名的地点与地盘 |
| `radius` | | 只用于 `region`：地盘半径，单位格，默认 8，1–64。没写 `operation=region` 却给了它会报参数错 |

## 目标对象（用于记住地点和圈地盘，省略就是 `here`）

| kind | 记下的位置（圈地盘时是中心） |
| --- | --- |
| `here` | 角色此刻脚下那一格 |
| `seen` | 观察编号指向的位置；实体是最后一次看到它的位置 |
| `landmark` | 另一个记住的地点的位置，用来给同一个地方再起一个名字，或以它为中心圈地盘；没记过这个名字时，认附近看得见、写着它的那块告示牌，记下牌子那一格 |
| `position` | 给的坐标；**必须给 `y`**——记住的地点会被出行当作确认过的目的地，不存猜的高度；不知道高度就先走过去，再用 `here` 记 |

`player`、`direction`、`previous` 不接受：玩家在场景里有观察编号，用 `seen` 指它。

## 圈地盘

- 地盘是一块明确的范围：中心加半径，按直线距离算。圈下立刻生效，之后所有任务都把里面的方块当受保护——拿东西、挖矿、施工、走路都不拆，里面的箱子不当成能取用的存储。不用再在任务许可里写它。
- 只想在某一次任务里避开一个地方，用任务许可的 `protected_landmarks` 写地点名；要长期护住主人的基地，圈成地盘。
- 地点和地盘是两本账：同一个名字可以既是地点又是地盘。`observe(what=world_memory)` 的 `regions` 列出每块地盘的名字、中心、半径。
- 里面的生物照旧按有名字、驯服、拴绳、围栏里判断受不受保护，圈地盘不改这一条。

## 边界与注意

- 记下的位置都带维度：目标对象没写维度的，按角色此刻所在的维度记。
- 同名覆盖：结果细节 `previous_position`（圈地盘还有 `previous_radius`）写出原来记成什么；没变就直接完成，说"本来就这样记着"。
- 忘掉：同名的地点与地盘一并忘，结果写出忘掉的是哪几样；两样都没记过就失败（`NOT_FOUND`），问题里附上记得的全部地点名与地盘名，不会把写错的名字当成已经忘掉。
- 结果细节：`name`、`operation`；记住地点时有 `position`，圈地盘时 `position` 是中心、`radius` 是半径；改记时有 `previous_position`（与 `previous_radius`）；忘掉时 `previous_position` 是忘掉的地点，`forgotten_region` 是忘掉的地盘。
