# remember — 记住或忘掉一个地点

让角色按名字记住一个位置（"这是家""那是矿洞口"），或者忘掉一个记过的名字。只改角色的世界记忆，不移动角色、不读地形、不核实那里能不能站人——这些交给真正去那里的能力。执行是当场完成的：`execute` 直接返回结果，不成为主任务，也不打断手上正在做的事；放进 `sequence` 时，按顺序轮到它才记。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `name` | ✅ | 地点名；首尾空白去掉后原样比较，不改大小写 |
| `operation` | | `remember` 记住（默认，同名覆盖）/ `forget` 忘掉 |

## 目标对象（只用于记住，省略就是 `here`）

| kind | 记下的位置 |
| --- | --- |
| `here` | 角色此刻脚下那一格 |
| `seen` | 观察编号指向的位置；实体是最后一次看到它的位置 |
| `landmark` | 另一个记住的地点的位置，用来给同一个地方再起一个名字 |
| `position` | 给的坐标；**必须给 `y`**——记住的地点会被出行当作确认过的目的地，不存猜的高度；不知道高度就先走过去，再用 `here` 记 |

`player`、`direction`、`previous` 不接受：玩家在场景里有观察编号，用 `seen` 指它。

## 边界与注意

- 记下的位置都带维度：目标对象没写维度的，按角色此刻所在的维度记。
- 同名覆盖：结果细节 `previous_position` 写出原来记在哪；位置没变时直接完成，说"本来就这样记着"。
- 忘掉：只忘名字对得上的那一个；名字没记过就失败（`NOT_FOUND`），问题里附上记得的全部地点名，不会把写错的名字当成已经忘掉。
- 结果细节：`name`、`operation`，记住时有 `position`，改记或忘掉时有 `previous_position`。
