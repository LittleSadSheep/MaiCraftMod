# vehicle_drive — 坐上驾驶座开载具

坐到载具的驾驶座上，接管控制件开它。现在能用的是 `operation=test`：逐条按住控制件看载具怎么动，再松开交还——开之前先弄清每个键让它往哪动。开到一个地方停稳（`operation=drive`）还没做。

现在认得的控制件是 Simulated 的**无线红石打字机**：接管后按键，它就往这个键绑的频率发信号，收端接着的螺旋桨轴承、燃烧室、转向机构跟着动。驾驶位是离角色最近的那台无线红石打字机；坐着够得着它的座位里挑最近的一个当驾驶座，没有这样的座位就站在它旁边按。

`vehicle` 给物理结构的观察编号 `s#`（`observe` 的 `mod_things.structure` 里看，`observe(detail)` 的 `controls` 列着上面有哪些控制件）。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `vehicle` | ✅ | 开哪辆：物理结构的观察编号 `s#` |
| `operation` | | `drive` 开到一个地方（默认，还没做）/ `test` 逐条试按 |
| `inputs` | test 必填 | `[{"control": "打字机:W", "ticks": 20}]`：按哪个键、按住几刻（1～200），最多 16 条 |

键的写法：`打字机:`（也认 `无线红石打字机:`）后面跟字母或数字（`打字机:W`、`打字机:1`），或 `空格`、`上`、`下`、`左`、`右`、`回车`、`tab`、`退格`、`shift`、`ctrl`、`alt`；英文 `typewriter:W`、`typewriter:space` 也认。

## 怎么做

1. 角色不在这辆上、或在上面但够不着驾驶位：先走过去——目的地是驾驶位旁的甲板格，上船那一段和 `travel` 一样由上下船接手（甲板离地太高走不上去会照实说）。
2. 腾出空手（拿着染料右键座位会给座位染色，无线红石打字机要空手才接管），坐上驾驶座。
3. 空手右键无线红石打字机接管，等服务器把它点亮（最多 10 秒）。已经被别人用着就不抢，照实结束。
4. 每条输入：先什么都不按看 8 刻（记下本来的漂移）→ 按住给定刻数 → 松开再看 10 刻（从按键到收端、到桨叶转起来有延迟）；每 5 刻记一次结构挪了多少、转了多少。
5. 全部按完交还无线红石打字机（和真人按 Esc 一样）。
6. 按每条的效果认出角色记进操纵表（试过的）：绕竖轴转得最明显是偏航（车是转向），升降最明显是升力或下降，平着挪最明显是动力——车头还没定就把这个方向当车头，定了反着走是倒车；车头定了时斜了是俯仰或横滚；都太小记 `none`。你用 machine_configure 定过的那条不改。中途失败时已经按过的照样写进结果，但不记进操纵表。

## 边界与注意

- 无线红石打字机原生不回报"收端通电了没有"：按下去只说明键发出去了，载具到底怎么动看样本和反应。
- 没绑频率的键不按（按了什么也不发），照实写明这台绑了哪些键；绑键用它自己的界面（潜行空手右键）。
- 按的过程中无线红石打字机断开（开着界面、走远了都会断）、从座位上掉下来、结构不见了：先松开按着的键再停，写明是哪一样。
- 被打断（吃东西、躲怪）时先松开按着的键，回来这一条从头再按。
- 样本是相对按下那一刻的：`dx`、`dy`、`dz` 是世界里向东、向上、向南挪的格数，`turn_x`、`turn_y`、`turn_z` 是绕结构自己三根轴转的度数（立着时 `turn_y` 就是偏航）。结构自己的轴就是组装那一刻的世界轴（组装不转方块），所以反应里的"沿结构 +z"就是造的时候朝南的那头。

## 结果

结果细节：`vehicle`（结构身份）、`seat`（怎么坐的）、`inputs`（每条：`control`、`ticks`、`pressed` 按下去了、`released` 松开了、`response` 一句话的反应、`effect` 同一件事的数（沿结构自己的 `x`、`y`、`z` 挪了几格，`turn_x`、`turn_y`、`turn_z` 转了几度，已扣掉漂移）、`note` 没按或中途停的原因、`samples` 每 5 刻的 `tick`、`held`、`dx`、`dy`、`dz`、`turn_x`、`turn_y`、`turn_z`）、`control_map`（试按后的整张操纵表与还缺的必需角色，同 machine_inspect）、`released`（本次按下的键都松开了）、`disconnected`（无线红石打字机交还了）、`note`（经过一句话）。
