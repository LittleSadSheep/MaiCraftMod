改一台机器的设置：侧面配置、过滤规则、模式、样板，按已装模组的机器类型来。target 指哪台机器：它的某一格（观察编号或坐标）。settings 写要改成什么：键是这台机器认的设置项，值统一写字符串，例如通用机械的侧面配置 {"side.north.item": "output"}（键是 side.方向.介质，值是 none、input、output……）；能设哪些项先 machine_inspect 看这台机器，或 lookup 查它的资料。

改身上物品自己的设置（机械动力的过滤器、属性过滤器写规则）时给 `item`（物品 ID），不看 target：身上有几件时 `inventory_slot` 指改第几格那件（0~35，副手 40），不给改第一件。角色把那件拿到主手、右键打开它自己的界面、逐项改、关上；关上后读主手那件的数据核对，结果写明改的是原来哪一格那件（`changed`），改完它在主手。能写哪些键先 machine_inspect(item=...) 看。

target 给物理结构的观察编号 `s#` 时改的是这辆载具的**操纵表**（不碰方块）：settings 的键写输入（`打字机:W`，取自 machine_inspect 的 `controls`）、值写角色——power 动力 / reverse 倒车 / brake 刹车 / lift 升力 / descend 下降 / yaw_left、yaw_right 左右偏航 / pitch_up、pitch_down 抬头低头 / roll_left、roll_right 左右横滚 / steer_left、steer_right 左右转向（车）/ none 不用它；键 `forward` 写车头朝结构自己的哪根水平轴（`+x` / `-x` / `+z` / `-z`，造的时候朝南那头是 `+z`）。你定的以你为准，之后试按不会盖掉；结果的 `control_map` 是合上推出来的、试过的之后的整张表，`missing` 写开这一类载具还缺哪个必需角色（飞艇要动力、升力、偏航，车要动力、转向，船要动力、偏航）。

无线红石打字机（装了 Simulated 才有，组装前在世界里绑）：target 给无线红石打字机那一格，settings 的键写 `key.W`、`key.空格`、`key.上`……（字母、数字，或 空格、上、下、左、右、回车、tab、退格、shift、ctrl、alt），值写这个键要发的频率——两格频率物品 `minecraft:iron_ingot + minecraft:redstone`，`none` 解绑。角色走到它跟前，身上要有这两样物品（绑键界面的频率格从身上拿；缺了照实说缺什么），存键表时带上原来绑的键不抹掉，读回核对。收端用同样两样物品当频率（机械动力无线红石链路的两格）就能收到。组装成结构以后在船上改键还不会。

target 给列车一节车厢的观察编号 `e#`、settings 写 `schedule.*` 时是给这趟车定**时刻表**（装了机械动力才有）：`schedule.1.station` 去哪个站（站名，可带 `*` 通配），`schedule.1.wait` 到了等什么（`delay 秒数`、`idle 秒数` 货物这么久没动、`powered` 车站通着红石、`unloaded` 车站那块没加载，几条用逗号隔开、都满足才走；不写按时刻表界面的默认等 5 秒），站号从 1 起连着编；`schedule.cyclic` 循环不循环（默认循环）。角色先认坐在列车操纵台座位上的生物（列车长；没有就照实说开不了——放生物上去由你决定，拴绳牵、引诱……），走到它跟前，把时刻表拿到主手（身上没有就去拿一张），写进去读回核对，再拿着它右键列车长交过去（手里那张被收走就是交上了）。列车原来有时刻表时列车长不收：空手右键先把旧的取下来回到背包，再写一遍交上去，只取一次；列车按表暂停着时空手点是让它继续、取不下旧表，会照实说。结果的 `schedule`：`written` 写进去了、`read_back` 读回的每一站、`replaced` 换掉了旧表、`handed` 交上了、`conductor` 列车长是什么生物。手动开车不做，时刻表就是列车的自动驾驶。

## 结果怎么读

- `applied[]`：每项的改前值与改后读回的值；本来就是要求的值也列出来，没有动手。
- 配置器一类是循环切换：改一下读回一次，到想要的值为止；读回的值转了一圈还到不了就停下，按做不到说，不无限点。
- 开界面改的一类（通用机械的物流分拣器）：走过去点开它的界面，看同步过来的规则，发它自己的按钮或新建规则，等服务器同步回新的样子再关上；这类设置只在开着界面时看得见，没打开过时读数是 unknown。机械动力方块上画着的设置框：过滤格 `filter` 写物品 ID（手持它点那一格，empty 清空），件数 `filter.amount` 写 any、<=N、=N，数值 `value`、选项 `option` 按 Create 设置界面那样改；能写哪些键先看这台机器。AE2 的样板供应器也是这一类：键写 `pattern.产出物品`、值写 in / out，把产出那样东西的样板放进去或拿回背包。
- 已经改好的项照实算数；后面的项做不了时结果是部分完成，没改的键在 `remaining` 里。
- `changes` 每项一条：改了什么、从什么改成什么。

## 问题种类

- `INVALID_PARAMETER`：settings 里这台机器不认的键，一次列全并附它认的键；或值没写成字符串。
- `UNREACHABLE`：目标那一格还没加载。
- `NOT_POSSIBLE_HERE`：循环切换到不了要的值；或分拣器已经有别的规则，只认一样物品要先去掉它们（原来的规则不擅自删）。
- `UNSUPPORTED`：这格没有机器类型认领（缺对应模组的联动），或这台机器不给改这一项。
