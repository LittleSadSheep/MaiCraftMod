# 钓鱼（maicraft:fish）

在附近的水边钓鱼。要求背包里有鱼竿，没有会先去弄一根；自己找站得稳的岸边、把钩抛到开阔的水面上，咬钩就收，钓上来的东西照单全收——鱼、垃圾、宝藏都算一次。count 是钓到几次；不给就一直钓，直到换别的活或取消。只从当前位置找水面，要去别的水边先 travel。

## 怎么用

- `count`：钓到几次收竿；垃圾、宝藏也算一次。不给就常驻钓。
- `max_seconds`：最多钓多久（秒）；到时按没进展结束，已钓到的照算。
- 不接受目标对象：给了地点或东西会按参数错误结束，异地先 travel。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `caught` | 完成的收获次数 |
| `casts` | 抛了几竿 |

钓到的每样东西一条 `item_gained`。钓不到的时候会写明原因：原地抛不出去、圈里有水但没有能站的岸、或圈里没看见水面（圈没扫到不等于圈外没有水）。
