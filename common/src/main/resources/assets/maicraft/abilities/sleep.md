# sleep 睡觉

找一张能用的床躺下，躺下即完成，不保证睡到天亮。

## 用途

天黑了去睡、或者在安全的床上把夜晚跳过去。target 用来指定在哪片床区睡（坐标、地点名、看到的床），不给就在附近找。

## 怎样算完成

- 附近有能用的床：走过去躺下就完成。自己睡过的床（还在、128 格以内）也算附近的床，离家不远就回家睡。床边有怪或床被占的床不算能用。点床被游戏拒绝时，按动作栏那句话当场认出为什么：床太远、床被挡先换一次站位再点，还不行换一张；床被占、周围有怪直接换一张；不是能睡的时间就结束。接连几张都不行才结束，`attempts` 里写着每次被拒的原话。同一夜里试过睡不上的床不再重选（跨过一夜才重算）。
- 去床的路上天亮了或被别人睡过：这一夜算已经度过，夜休任务回去继续干活，不算失败。
- 附近没床：放下一张自带的床，或者现做一张（附近没有床、身上也没有时，走拿到物品的途径去弄一张床，弄不到时以缺东西结束，写明缺什么）。
- 白天被叫去睡不干等：先把今晚的床备好（身上带着、或 32 格内有能用的床才算备好；备床期间发生的变化记在 `changes` 里），然后以"部分完成"结束，`details.bed_ready_for_tonight` 说明床备好没有，`remaining` 写着"入睡"；天黑后夜间自动休息会在干活间隙自己去睡。
- 在下界或末地直接结束（这个维度的床会爆炸），不做尝试。

## 夜里自动去睡

默认开着：天黑了有床，就在干活间隙自己去睡，醒了回到原来的位置。夜里自己去睡只去 32 格以内的床，更远的（自己睡过的家里那张也一样）不去：身上带着床就就地放下睡，没有就不去睡，露天又打不过照旧挖坑自保。睡着时只有挨打、着火这类急事和要命的事会把人叫起来，饿了等醒来再吃。睡醒收回自己放下的床：收的途中被打断，处理完回来先走回床边接着收；实在收不了就如实结束，结果和事件写明床留在哪、重生点是不是也改到了那里。放床那条 `changes` 的 `note` 带着坐标，收回了另记一条 `block_broken`。有人说"晚上别睡"（多人游戏里别人想熬夜）时用 `operation=auto_off` 关掉，关着时夜里不会自己去睡，露天又打不过照旧挖坑自保；`auto_on` 打开，`auto_status` 查开没开。开关当场生效，不动手；进新世界回到开。

## 结果怎么读

- `details.entered_sleep`：确认躺下了。
- `details.bed_source`：床从哪来——`world` 世界里原有的床；`carried` 放下了自带的床；`crafted` 现做的床。
- `details.bed_ready_for_tonight`：白天被叫去睡时，今晚的床是否已备好。
- `details.night_skipped_by_sleep`：一觉睡到了天亮。
- 试过哪些床、被游戏怎么拒绝的，见 `attempts` 与 `unconfirmed`。
