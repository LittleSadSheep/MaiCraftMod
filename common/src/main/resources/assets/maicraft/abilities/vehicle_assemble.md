# vehicle_assemble — 把建好的方块组装成会动的结构，或拆回方块

把建好、胶好的方块组装成会动的结构：飞艇、车、船用 Simulated 的物理组装器（组装器要贴着要组装的方块放，强力胶或蜂蜜胶把整艘船框起来）。角色走到组装器跟前，看着它拉一次杆，Sable 把粘在一起的方块变成一个会动的结构；拆回就是对结构上的组装器再拉一次（结构要先停稳）。

`target` 指组装器：组装时给组装器的坐标（或它附近，8 格内找最近的组装器）、记过的地点；拆回时给结构的观察编号 `s#`（observe 的 `mod_things.structure` 里看）。

列车在车站组：转向架、列车操纵台、外壳、座位先在车站前的轨道上放好、用强力胶粘好，`target` 给车站（坐标或观察编号 `b#`，8 格内找最近的车站）。角色走到车站跟前，切到组车模式（车站界面上那个按钮），按一次"组装列车"；站前出现新的一趟车就是组成了，没成照组车界面上显示的那句原因说（转向架不对、没胶好……）。`operation=disassemble` 加车站就是把停在站里的车按"拆解列车"拆回方块。站里已经停着车再组、站里没车再拆，都直接完成。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `operation` | | `assemble` 组装（默认）/ `disassemble` 拆回方块 |

## 边界与注意

- 只拉一次：再拉一次会反过来（组装好的会拆回去），所以拉过之后不管成没成都不再拉，照实告诉你。
- 拉了 3 秒没转换不算失败：结果里写明"拉了一次杆，但没有变成会动的结构"——多半是胶没粘全、组装器没贴着要组装的方块，或结构太大；看了再改。
- 已经是要的样子（组装过了、已经是方块）直接完成，什么都不做。
- 斜对角相接的方块也会被带进结构；用黏液球能把两个结构并成一个，断开的部分会自己分离（这是 Simulated 的规矩）。
- 机器档案还不会跟着迁到新结构上：组装后用结构的观察编号 `s#` 指它。

## 结果

结果细节：`structure`（组装出来或拆回前的结构身份）、`already_done`（开始时就是要的样子）、`converted`（拉了之后真的转换了）、`blocks`（组装进结构的方块数，拆回为 -1）、`note`（经过一句话）。
