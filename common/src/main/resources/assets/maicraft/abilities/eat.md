# eat 吃东西

吃身上带着的食物：挑一种，换到主手，原生长按吃完。

## 用途

饿了补充饱食度。找食物只在身上找（主背包、副手），不会现去打猎或合成——那分别是能力 obtain 与 craft 的事。

## 怎样算完成

- 吃完了要吃的件数，`changes` 里逐件记下消耗，`details.effects_gained` 列出吃出来的状态效果（普通食物为空）。
- 没点名要吃什么且已经饱了：直接完成，写明"开始时已饱"。
- 点名的食物身上没有：以缺东西（NEED_ITEM）结束；点名的东西本身不能吃（没有食物组件）：以不支持（UNSUPPORTED）结束，要用它请下 use。
- 饱食度已满时普通食物吃不下：以时间不对（WRONG_TIME）结束；金苹果这类"饱腹也能吃"的照吃。创造模式没有饥饿机制，同样直接结束。
- 没点名就是"随便吃点"：只在普通食物（不带效果、饱腹时不能吃的）里挑补得多的；没有普通的，再吃只会让人更饿的垃圾食物（腐肉、生鸡肉）。金苹果这类珍贵的、紫颂果（吃了会随机传送）、会中毒的（河豚、蜘蛛眼、毒马铃薯）要点名才吃；身上只剩这些时以缺东西（NEED_ITEM）结束，写清身上有哪些。

## 结果怎么读

- `changes`：吃掉了哪种、几件；期间腾地方或顺手拾取产生的其他变化也会如实列出。
- `details.effects_gained`：吃之前没有、吃完之后身上多出来的状态效果。
- 按住吃完是持续动作：中途被更急的事打断时，已吃进去的照实记账，剩余的没吃。
