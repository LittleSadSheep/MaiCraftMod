# travel — 走到一个地方

走到一个地方：给坐标（高度不确定就别给 y：那一列看得见时落在那里的地面上，远处没加载的先走到那一列再找能站的格子；给了 y 就按这个高度去，这个高度在山里、地下也会挖过去）、叫得出名字的地点、看得见的东西（观察编号），或"往某方向走多远"。默认可以挖开天然方块、垫临时方块来开路（挖是绕不开时的下策：挖一格约等于多走六七格，十几格内有门就走门，不从墙根、地板底下钻进屋），垫了什么会如实告诉你；垫的先用泥土、安山岩这类随处可见没什么用的，圆石排最后，上一个目标刚拿到的、手上正在拿的东西留够数不垫；不许动地形时只走不改，走不过去会说明原因。过河靠游，上坡靠爬或垫。走到、站实、落地才算到。目的地附近 radius 格里一格能站的都没有（比如床边 1 格，四周不是墙就是床本身）时，放宽到最近有能站的那一圈（最多再放三格），结果里的目的地写着放宽后的格数。

去哪用目标的 target 说明（`position` / `landmark` / `seen` / `here` / `direction` / `dimension`），不用参数。

## 去别的维度

目标写 `{"kind":"dimension","name":"minecraft:the_nether"}` 就是去那个维度；坐标带 `dimension` 字段就是"那个维度的这个坐标"（坐标按目标维度自己的坐标系写，到了接着走过去）。先在附近找现成的活门：走近、直走进门、传送，到了先走出门口几步再报位置，免得又被传回去；下界的落点按主世界与下界 1:8 换算给出预期与偏差。查遍已加载区没有活门：像正常玩家一样就地搭一扇——先补附近残缺的黑曜石框；没有框就看身上：黑曜石够十块就在脚边挑块平地摆框；不够就在同样的范围里找岩浆池，找到合规的池岸（岸边四格连成一线的岩浆源、池里连通的岩浆够浇一扇门、岸上站得住）就像速通玩家那样浇：拿空桶去 48 格内舀一桶水、备几块不怕火的石头（圆石、泥土），填直弯岸、铺好站台，用一块石头挡住一格岩浆、旁边倒水、再挖掉挡块让水流过去浇出门底，砌六块挡水的模具、高处倒水，再一桶一桶从池里舀岩浆浇进框的每一格，收水、拆模具；池也没有才去弄黑曜石（没钻石镐会说缺什么）。备好打火石（没有则火弹）点火，门面出现才进门；动地形与备料都按这次的许可来，材料备不齐（桶、水、石料、黑曜石）会说缺什么；浇到一半某格成了圆石不再倒第二桶，门框没成型如实停下，结果里写门是摆的（`obsidian`）还是浇的（`lava_casting`）。附近没有合规池岸时结果写清查了多大范围、看到几格岩浆源、各因什么被拒，要找池可以用 `explore` 留意 `minecraft:lava`。去末地走末地传送门：已加载区没有开着的门，就按记过的要塞线索找到末地门房间，把空着的眼逐格插上末影之眼（要用稀有物品的许可），插满门开；**末地门是单程**，回程要打败末影龙（归战斗）或死回来。下界与末地之间没有原版门，要经主世界中转；模组维度去不了，会如实说明目前只支持主世界、下界、末地。

## 换交通（装了联动模组才有）

远的地方可以换交通：楼里有 Create 电梯就坐电梯。不指定时近处（水平 32 格、高差 6 格以内）直接走，远处或走不通就比"走过去"和"坐一段再走完剩下的"哪个快；指定 `via` 就只用那一种，用不了会说明原因，不会悄悄改成走路。一段没坐成、人还好好站着，不算整趟失败，从停下的地方接着规划，同一份报价这一趟不再试；每段怎么走的写在 `legs` 里。

坐电梯：走到这层电梯口，轿厢不在就呼梯：触点旁的按钮、和触点旁无线红石接收端同频的发射端旁的按钮（角色 32 格内、在无线距离内）、身上遥控器绑了同一频率的键都算，近的先试（按钮在 5 格外先用遥控器，不用走），一种没用成（走不到、遥控器拿错）换下一种，都按过了轿厢还不来再按一次（已经叫过、正往这层来就不再按），等轿厢停稳，走进轿厢里面一点，在装置控制器上选层，站着别动，到了从门口走出去（最近的出口被挡就换下一个），在固定平台上站稳才算到；轿厢 10 秒一点没动就停在当前安全处如实说；一种呼梯办法都没有时写明触点旁有没有无线接收端、频率是什么、找过哪些。只想换楼层就给 `via=elevator` 和 `floor`，不给 target；楼层名写错会列出这台电梯实际有哪几层。

上下船（装了 Sable 才有）：飞艇、船、车这类物理结构上的方块寻路看不见，所以站在船上出发时第一段固定是下船（船停稳才走，走到船沿迈下去，落差三格以内），目的地在船上（`target` 给船的观察编号 `s#`，就是上去站稳）时最后一段是上船（找船边比地面高不过一格的地方迈上去，高一格会跳一下，站稳 8 刻）；船一直在动就等它停，等太久如实说，不跳下移动的船。甲板离地太高走不上去会写明高多少。

坐火车（装了机械动力才有，要服务器也装了 MaiCraft 才查得到时刻表）：起点附近 96 格内有车站、终点附近也有，有车把两站连起来（直达，或一次换乘）就坐车：走到站台，等那趟车进站停稳（最多等 2 分钟，没来会说哪趟车没来），走到空座位旁右键坐上去，坐着别动，到站停稳后潜行下车，再走完剩下的路；换乘时下车后再查一次接着坐。车上没空座、半天离下车站一点没近（在它停靠的那一站下车）都会如实说。

飞过去（装了机械动力：喷气背包才有）：身上有喷气背包（背包里的会先换上胸甲槽，落地后换回原来的胸甲）、背罐有气，目标附近有看过、能站、上面留得出净空的落脚处才飞；一次只规划 64 格，更远的先朝目标方向飞到中途能站的地方再接着走。不指定方式时，坑道、矿洞、低矮屋里这类头顶贴着的路段按飞得很慢算（喷气背包在里面得一点点挪），能走出去就走，走不通才在里面飞。打开飞行与悬停，沿看过的空中直线一段一段飞，巡航按着疾跑；到落点正上方关掉背包自由落，按下落速度和网络延迟算好时机，快到地面瞬间打开一下（重新算摔落高度、把下落压住）、读回开了马上关掉落地（开着慢慢飘会摔伤，还要飘很久），打开后停得还高就关掉再落一次，下面是水就直接落；落地后开关拨回起飞前的样子。暂停、取消或不急的事打断时，这一段此刻停下不安全就先到安全的地方停下（飞着的就近落地、在轿厢里的等停靠出来、开的载具就近降落刹住），停下了再暂停或去办，恢复后从站的地方接着规划；坐着的火车停得下，原地停。气不够飞完先落到近处，飞着挨打就往离打的那家伙远的地方落下交给自卫，都会写在 `legs` 里，再从落下的地方接着规划。意外往下掉时，穿着有气的喷气背包会先开悬停刹住，比放水桶优先。

喷气背包没气了怎么充（机械动力的规则，和铜背罐一样）：拿着它对着方块右键，放下来就是一个方块；在它**正上方**接一根转着的传动杆（连着应力源的那套传动），就按转速往里充气——转得越快充得越快，256 转大约十秒充满，32 转要十来分钟，泡在水里不充。充好后胸甲槽空着、手上不拿方块，空手右键它就直接穿回身上，气都在；胸甲槽有东西时先把胸甲脱下来再去拿。`observe` 看自己时 `gear_bars` 里喷气背包那一条就是剩多少气。

开自己的载具（装了 Simulated 才有）：给 `via=vehicle`（或直接给 `vehicle` 指哪辆）才开，不指定时不会擅自开船。开哪辆：`vehicle` 给结构的 `s#`，不给就用角色正站在或坐在上面的那辆。先走到驾驶位旁（不在船上就挑离驾驶位近的那一边上船，再在甲板上走过去），坐下、接管无线红石打字机，和 `vehicle_drive` 一样开到目的地附近停稳、交还，然后照常下船、走完最后一段。操纵表缺必需角色（飞艇要动力、升力、偏航，车要动力、转向，船要动力、偏航）或车头没定就用不了这种方式，会说缺哪个——先用 `vehicle_drive(operation=test)` 试按或 `machine_configure` 定角色。半路停下（时间用完就地降落）从停下的地方接着规划。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `radius` | | 到达容差，单位格，默认 2；给 0 表示必须站进那一格 |
| `max_distance` | | 找传送门的范围，单位格，默认 128；查遍已加载区没有门才建门 |
| `max_seconds` | | 最多走多久（秒）；超时以卡住结束，写明停在哪、离目标多远 |
| `via` | | 用什么方式去：`walk` 只走路，`elevator` 坐电梯，`train` 坐火车，`jetpack` 飞过去，`board` 上下船，`vehicle` 开自己的载具……装了相应模组才出现，参数表里列出当局可用的取值；不给就自己挑 |
| `floor` | | 只配 `via=elevator`：去哪一层，楼层名或 `top` / `bottom` / `up` / `down`；只换楼层时不给 target |
| `vehicle` | | 只配 `via=vehicle`：开哪辆（物理结构的观察编号 `s#`）；不给用角色正站在或坐在上面的那辆 |

可给 `permissions`：`change_blocks` 决定能不能挖路、垫路、建门（默认 `natural`，`none` 时没有门也不会建门）；`use_rare_items` 决定能不能插末影之眼；`protected_landmarks` 把地方加入不许碰的名单。

## 结果细节

| 字段 | 含义 |
| --- | --- |
| `arrived_at` | 实测到达位置 x/y/z |
| `remaining` | 没走到时的剩余水平与垂直距离、八向方位（partial / 卡住 / 走不过去时） |
| `placed_blocks` | 这次垫上的临时方块格子（也在 `changes` 里） |
| `crossed_water` | 这段行程有没有泅渡 |
| `landings` | 每次落地救援的经过：放了什么接住自己、收没收回、掉没掉血 |
| `trap_escapes` | 每次卡坑自动脱困的经过：没等许可垫方块或挖天然方块出坑，垫了几块、挖开几格 |
| `legs` | 换交通时每段：`via`、起止位置（`from` / `to`）、用了多少刻（`ticks`）、结果（到了，或停在哪、为什么；坐电梯的写从哪层到哪层，坐车的写车名与上下车站） |
| `arrived_dimension` | 跨维度时实际到达的维度 |
| `portal_at` | 这次进出用的门的位置 |
| `portal_built_how` | 这趟自己建了门时门是怎么建的：`obsidian` 摆的黑曜石 / `lava_casting` 在岩浆池岸浇的；没建为 null |
| `expected_landing` / `landing_offset` | 跨下界按 1:8 换算的预期落点与实测偏差（格） |

## 边界与注意

- 乘船还不支持，会以 `UNSUPPORTED` 如实说明，不做变通；电梯要装了机械动力、飞要装了喷气背包才有。
- 走路会绕开会动的机械动力装置：转着的风车整个扫过的地方、开着的列车与活塞前面的路、电梯井都不进；路被正在动的东西挡着就先等它过去（最多 5 秒）再绕。
- 垫上的临时方块不自动收回；要不要拆由你看了结果再决定。
- 穿着喷气背包、背罐里气够时，路上要上两格以上的高处会直接飞上去，不再一块块垫方块往上搭；落地后喷气背包会关上。
- 卡进坑里（只走出不去的小坑、见不到天的封闭空间）时不等你放宽许可：只走到不了就先垫方块往上搭，还不行再挖天然方块，出坑后按原来的许可接着走；受保护的、别人的方块不动，经过写在 `trap_escapes`。围起来见得到天的大院子不算坑。
- 跟着某位玩家走不是出行的目标对象；要跟人，用跟随类能力。
- 叫不出名字的地方先去记住它，或改用坐标；解析不了时会向你提问，不会拿脚边顶替。
- 末地路线只能送进去：打龙与回程归战斗域；末地里让它"回主世界"会如实说做不到。
