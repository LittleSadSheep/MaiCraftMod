# travel — 走到一个地方

走到一个地方：给坐标（高度不确定可以不给 y，到了附近自己找能站的格子）、叫得出名字的地点、看得见的东西（观察编号），或"往某方向走多远"。默认可以挖开天然方块、垫临时方块来开路，垫了什么会如实告诉你；垫的先用泥土、安山岩这类随处可见没什么用的，圆石排最后，上一个目标刚拿到的、手上正在拿的东西留够数不垫；不许动地形时只走不改，走不过去会说明原因。过河靠游，上坡靠爬或垫。走到、站实、落地才算到。

去哪用目标的 target 说明（`position` / `landmark` / `seen` / `here` / `direction`），不用参数。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `radius` | | 到达容差，单位格，默认 2；给 0 表示必须站进那一格 |
| `max_seconds` | | 最多走多久（秒）；超时以卡住结束，写明停在哪、离目标多远 |

可给 `permissions`：`change_blocks` 决定能不能挖路、垫路（默认 `natural`）；`protected_landmarks` 把地方加入不许碰的名单。

## 结果细节

| 字段 | 含义 |
| --- | --- |
| `arrived_at` | 实测到达位置 x/y/z |
| `remaining` | 没走到时的剩余水平与垂直距离、八向方位（partial / 卡住 / 走不过去时） |
| `placed_blocks` | 这次垫上的临时方块格子（也在 `changes` 里） |
| `crossed_water` | 这段行程有没有泅渡 |

## 边界与注意

- 里程碑一只有步行：目的地在别的维度、乘船、飞行、电梯都还不支持，会以 `UNSUPPORTED` 如实说明，不做变通。
- 垫上的临时方块不自动收回；要不要拆由你看了结果再决定。
- 跟着某位玩家走不是出行的目标对象；要跟人，用跟随类能力。
- 叫不出名字的地方先去记住它，或改用坐标；解析不了时会向你提问，不会拿脚边顶替。
