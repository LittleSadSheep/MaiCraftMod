# timer — 不占身体的计时：过 N 秒叫你一声

想"炉子烧十分钟再回来看""作物差不多熟了去收"时用它：设一个"过 N 秒叫我"，附一句备注。不占身体：`execute` 当场返回，不成为主任务，也不打断手上正在做的事，角色这期间照常干别的。到点在任务事件流里发一条 `timer_due`，消息带计时编号、你写的备注、设了多少秒和到点时的游戏时间，例如"计时 3 到点：看炉子烧好没（600 秒前设的；此刻白天）"。`events` 等得到它（不带 `goal_id` 读，它不挂在任何目标上）。放进 `sequence` 时，按顺序轮到它才设。

要角色站在原地等到天黑、等血回满，用 `wait`；这里只是到点叫你，不看条件、不动角色。这不是红石电路或模组里的计时器方块。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `operation` | | `set` 设一个计时（默认）/ `cancel` 按 `timer_id` 取消一个 / `list` 看还挂着哪些 |
| `after_seconds` | set 必填 | 过多少秒叫你，1–3600 |
| `note` | set 必填 | 到点时原样带回的一句备注（最多 200 字），写清到时要看什么、做什么决定 |
| `timer_id` | cancel 必填 | 要取消的计时编号（`set` 的结果里给的） |

参数和操作对不上（设计时没写备注、取消时带了 `after_seconds`……）会一次报全（`INVALID_PARAMETER`），不会设上。不接受目标对象。

## 怎么计时

- 按游戏时间算（每秒 20 个游戏刻）：服务器卡了计时跟着慢，单人游戏按 Esc 暂停时不走，和炉子烧东西、作物生长用的是同一只钟。睡觉跳过夜晚不会让它提前到点。
- 同时最多挂 8 个。挂满了再设会失败（`UNSUPPORTED`），`details.pending` 列出挂着的那几个；等一个到点，或取消一个不要的。
- 换世界、断线时没到点的全部清掉，不会在下一个世界里叫你；编号只增不减，旧编号取消不到新计时。
- 人按 F8 接过角色时照样到点叫。

## 结果细节

| 字段 | 含义 |
| --- | --- |
| `timer_id` | 设下或取消的那个计时的编号 |
| `after_seconds` | 设的时候说过多少秒叫 |
| `note` | 那个计时的备注 |
| `pending` | 做完这次之后还挂着的全部计时，先到点的排前面：每项 `timer_id`、`remaining_seconds`（离到点还有几秒）、`note` |

取消一个已经到点叫过、换世界清掉或写错的编号会失败（`NOT_FOUND`），`pending` 照样列出挂着的。
