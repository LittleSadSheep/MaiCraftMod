对一个方块或实体用一下手上的东西，就像玩家按一下右键：开门、按按钮、拉拉杆、打开箱子看看里面有什么、骑上马或船、剪羊毛、挤奶、用桶舀水或倒水、用打火石点火、用锄头耕地、用刷子刷可疑的沙子或沙砾、在告示牌上写字。不给 item 就空着手用；身上没有 item 会先去拿一件。target 指定对哪个东西用；只给 block 或 entity 时，用附近最近的那一个。count 是做几次。打开的界面会在列出内容后关上。刷子要对着一格用（可疑的沙子、沙砾），会一直按住直到那一格变回普通方块，刷出来的东西捡回背包。放方块用 build，挖和砍用 gather，打怪用 fight，吃东西用 eat，存东西用 deposit，从箱子里拿东西用 obtain。

## 结果怎么读

- `applied_times`：确认生效了几次。某一次没有效果就停下，做成了几次就写几次。
- `opened`：打开过的界面，里面有什么（按物品合并）。看完就关上了。
- `sign_text`：告示牌上实际写下的字，逐行。超宽的行游戏会截掉，没写上去的部分在 `remaining` 里。
- `riding`：骑上的东西。目标本来就是正骑着的坐骑时，直接完成。
- `unconfirmed`：点下去了却没能确认有没有生效的那一下。不会再点第二次去赌，结果是部分完成。
- 空桶点到流动的水时，改舀 8 格内最近的同种水源。

## 问题种类

- `TARGET_GONE`：观察编号对应的东西不在了，或那一格的方块变了；重新 `observe` 拿新的编号。
- `NOT_FOUND`：查过的范围内没有目标（只查已加载的区域）；换个地方，或用 `find`。
- `DANGER`：下界、末地的床和主世界、末地的重生锚右键会爆炸，不会去点。
- `NEED_ITEM`：身上没有要用的东西，也没办法拿到一件。
- `NEED_APPROVAL`：这样用会改动它（倒流体、点火、耕地、剪毛、挤奶、喂食、染色这类），而目标是别人的（玩家放的、在玩家地盘里的方块，有名字、驯服、拴着、圈着的生物）。开门、按按钮、拉拉杆、打开箱子看看、空手骑乘不受这条限制。确实要用，先 `observe` 再用观察编号点名它；按类型找时附近只有别人的也会这样说。
- `REFUSED_BY_GAME`：游戏拒绝了这次交互（上锁、领地保护、上过蜡的告示牌），附上游戏给的原话。
- `NOT_POSSIBLE_HERE`：这样用没有效果；换个目标或换个用法。
- `UNREACHABLE`：试过的站位都够不着或看不见目标。
- `UNSUPPORTED`：弓、弩、三叉戟、盾牌、望远镜、钓竿这类要凭时机松手的物品不接，指向对应的能力；掉落物、经验球、射出去的箭准星选不中，捡东西用 gather。
