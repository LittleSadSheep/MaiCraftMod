# equip 穿装备 / 卸装备

把身上的装备穿到指定栏位，或从栏位取下放回背包。

## 用途

捡到头盔就戴上；身上已经戴着同一件（按物品类型比，不看耐久与附魔）就不再穿一遍。卸下是把装备脱下来放包里，不是丢弃。

## 怎样算完成

- `operation=equip`：东西穿到了指定栏位，`changes` 记下穿上了什么。目标栏位已经穿着同一件时直接完成，写明"已经戴着"。
- `operation=unequip`：栏位取下放进了背包；`slot=armor` 表示整套护甲卸下（穿戴永远一次一件，`equip` 不接受 `armor`）。
- 没点名穿哪件时：身上候选唯一就自动选；有几种不同的候选会提问选一个（穿哪个后果不同）。
- 物品类型和栏位不匹配（头盔进不了胸甲栏）按游戏规则做不到，直接结束。
- 卸下需要背包有地方放：先按腾背包的次序腾（合并、进随身包、存附近箱子、丢垃圾），要动到贵重品才会停下来；腾不动以背包满（INVENTORY_FULL）结束。
- 没能确认结果的穿卸记在 `unconfirmed`，不要按确认过处理；整套卸下没卸完时结果为部分完成，`details.still_worn` 列出还穿着的栏位。

## 结果怎么读

- `changes`：穿上了什么、卸下了什么；卸下期间腾背包的存放与丢弃也逐条列出。
- `details.still_worn`：只在卸下且没卸完时出现，是仍穿着的栏位列表。
