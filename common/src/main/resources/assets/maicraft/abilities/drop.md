# drop 丢东西

把身上带的东西丢到地上：朝面前远处整份抛出，然后走开，不让自己又捡回来。

## 用途

清理背包、把东西丢给别人。**丢弃不可逆**：丢出去的东西任何玩家或熔岩都拿得走，下达前想清楚数量。

## 怎样算完成

- 丢出了要的件数：`changes` 里逐份记下丢出的东西；丢完会走开几步，落点也登记进寻路避让，之后走路不会踩进自己的丢弃堆。
- 请求超过实际持有：按实际持有的丢，结果为部分完成，`remaining` 写清还差几件——不提问，少丢不冒充多丢。
- 身上一件都没有：以缺东西（NEED_ITEM）结束。
- 抛出没等到游戏确认：记在 `unconfirmed`。没等到确认不等于确定没丢，也不要重复下达同一笔；先查背包再说。
- 这个能力不做销毁——不想被捡回时用能力组合（丢出去 + 点火），火与烧毁另行处理。

## 结果怎么读

- `changes`：已确认丢出的件数。
- `unconfirmed`：提交了抛掷但没等到确认的部分，不能当作已丢或没丢。
- `remaining`：还差几件没丢，以及为什么。
