把 target 那台机器接进一张网络：已经接着就不动；没接上就规划一条线路、铺好，再核对两端在不在同一张网、接上了转不转得动。`network` 指接哪种网（取值由这个实例装了的联动决定，例如 kinetic 应力、me、energy）；`source` 指接到哪（观察编号、[x,y,z] 坐标、或一个名字），不给就在 radius 内找挂着这种网的格子，在转的机器旁边那格优先。目标指档案名时，线路并进那份档案，接上了会把这张网记进档案；没有档案的按目标那一格起一份。

## 线路怎么铺

- 线材由那种网的联动给：应力网近处用传动杆、拐弯用齿轮箱，远处从来源网里已有的链条输送机跨过来、在机器附近放一台新的再短接（每台机器链条输送机的个数有上限，由实例配置定）。
- 直线优先、少拐弯；只铺在空气、草这类能直接放的格里，不挖方块；拐弯处不贴着别的动力方块，免得把别的机器连进来。
- 铺线用的是 `machine_build` 的同一套施工：缺料自己去拿，结果里 `route` 列出每格放了什么。找不到空路时如实说，清出一条路或换个 source 再试，也可以自己写蓝图用 `machine_build` 铺。

## 结果怎么读

- `joined`：两端是不是同一张网；`running`：接上了的话机器在不在转。两个分开给——接上了但转速为 0、过载，说明线路是通的、动力那边的事，读数在 `summary` 里。
- `summary`：那张网现在的读数（应力容量与用量、频道、能量存量……）；读不到时写明原因。
- `route`：这次铺的线路，每格是什么、在哪；跨越写成一行。

## 问题种类

- `INVALID_PARAMETER`：network 没有对应的读取器（这个实例没装那个联动，或取值拼错），或 source 写法不对。
- `NOT_FOUND`：radius 内没有挂着这种网的格子；把 radius 调大或用 source 指一台在网的机器。
- `UNREACHABLE`：目标那一格还没加载，或档案在另一个维度。
- `NOT_POSSIBLE_HERE`：两端之间找不到全是空格的走法，或要接的机器没有能接这种线的面。
- `UNSUPPORTED`：两端还没在同一张网上，而那种网的联动没有给出接线的方块。
- 铺完两端还不在同一张网：按部分完成交代，已经放下的线材不拆，用 `machine_inspect` 看看哪里断了。
