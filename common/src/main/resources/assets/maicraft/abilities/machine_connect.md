把 target 那台机器接进一张网络：核对两端在不在同一张网、接上了转不转得动。`network` 指接哪种网（取值由这个实例装了的联动决定，例如 kinetic 应力、me、energy）；`source` 指接到哪（观察编号、[x,y,z] 坐标、或一个名字），不给就在 radius 内找挂着这种网的格子，在转的机器旁边那格优先。目标指档案名时，接上了会把这张网记进档案。

## 结果怎么读

- `joined`：两端是不是同一张网；`running`：接上了的话机器在不在转。两个分开给——接上了但转速为 0、过载，说明线路是通的、动力那边的事，读数在 `summary` 里。
- `summary`：那张网现在的读数（应力容量与用量、频道、能量存量……）；读不到时写明原因。
- 已经验证两端同网就完成，不再动一根轴一段线；没接上时如实说差哪一段，铺线路要哪种方块、怎么铺由各网络的联动给，没有登记的途径能给出时接线路动不了手，不会猜着铺。

## 问题种类

- `INVALID_PARAMETER`：network 没有对应的读取器（这个实例没装那个联动，或取值拼错），或 source 写法不对。
- `NOT_FOUND`：radius 内没有挂着这种网的格子；把 radius 调大或用 source 指一台在网的机器。
- `UNREACHABLE`：目标那一格还没加载，或档案在另一个维度。
- `UNSUPPORTED`：两端还没在同一张网上，而铺线路需要的线材与铺法没有登记的联动能给出。
