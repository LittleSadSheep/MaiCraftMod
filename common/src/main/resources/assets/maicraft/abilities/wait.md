# 等待（maicraft:wait）

在游戏里等一个条件：等到天黑或天亮、等生命回满、等不再饥饿，或单纯等一段时间。只观察，不会为了达成条件去做任何事——等血回满不会自己去吃东西。没有超时，等不到会一直等；要设上限或中途停下，用 goal 取消。

## 怎么用

- `condition` 选一个：`elapsed`（只等时间，默认）/ `day`（等到白天）/ `night`（等到夜晚）/ `health_full`（等血回满）/ `not_hungry`（饱食度回到 18 以上，原版自然回血线）。
- `after_seconds`：先至少等这么多秒再开始查条件（0..3600，默认 0）；`elapsed` 条件下过了这段时间即完成。
- 被生存需求打断的暂停同样算已经过去的时间，不会重新计时。

## 结果怎么读

| 字段 | 含义 |
| --- | --- |
| `waitedSeconds` | 实际经过的秒数 |
| `conditionMet` | 成立的那个条件 |

参数写错（条件名不在五个里、秒数越界）会在创建阶段一次报全，不会开等。
