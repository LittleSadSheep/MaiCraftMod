用一台机器做东西：备料、投料、开机、等产物、收产物，一台机器一次。target 指哪台机器（观察编号、坐标或记过的地点，指它的某一格）。`item` 是要做出什么，不给就只开机；`count` 要做几件；`collect` 要不要把出口的东西拿回背包（默认要）；`max_seconds` 最多等多久（默认 300）。一条生产线上有几台机器就是几次 machine_run，或者用 sequence 排。

## 结果怎么读

- `recipe`：用的配方（类别与注册 ID）和按 `count` 算出的批数；查到多条都能做时用第一条并写明。
- `fed[]`：投进机器的东西与数量；配方要的流体、化学品带不进机器，写进 `notes`，做不做得看机器里还有没有。
- `produced`、`collected`：出口里这次新增几件（开始时已有的不算）、拿回背包几件。
- `machine`：结束时机器的读数与挂着的网络读数。机器在转不、动力够不够这里不预判：照常投料开机，等不到产物时读数会说明原因（转速 0、过载）。
- 没加工完的原料留在机器里不收回，下一次接着用；出口里拿不走的如实写。
- 等产物期间可以插别的事，回来接着等。

## 问题种类

- `NOT_POSSIBLE_HERE`：查到的配方里没有这台机器做这个的；先 lookup 查它能做什么。
- `NEED_ITEM`：投料要的东西没拿齐。
- `UNSUPPORTED`：这格没有机器类型认领（缺对应模组的联动），或这台机器不收这种料。
- `STUCK`：到等待上限或久无新货时出得不够，按部分完成收场，附机器读数。
