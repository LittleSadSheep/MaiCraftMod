# chat — 向游戏聊天发一句话

让角色对着全体玩家说一句话，像玩家在聊天栏打字发送一样：角色会真的打开聊天框，把话一个字一个字打出来（每个完整可见字符约 0.1 秒，组合表情按一个字），整句打完停一下再提交。所以长句子要打好几秒，急话拆短了说；打字途中生存需求（换气、撤离这些）会先插进来自救，聊天框暂时关掉，回来接着把剩下的字打完，没打完的话不会发出去半句。聊天框被别的界面占着时会等它让出来（最多约 3 秒），等不到以问题种类 `REFUSED_BY_GAME` 收场、说明框被占。

发出后以聊天栏出现自己那条（本地回显）为完成依据；回显读不到时结果会说明"已提交但没能确认"，并在 `unconfirmed` 里记一条——这时不要盲目重发。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `message` | ✅ | 要发到游戏聊天的话，全体玩家可见；以 `/` 开头的是游戏命令，角色不执行 |

## 边界与注意

- 角色不执行游戏命令：`message` 以 `/` 开头会被直接拒绝（问题种类 `REFUSED_BY_GAME`），要发普通聊天去掉斜杠照常。
- 读别人的聊天、听别人说话不属于本能力，那归观察侧。
- 结果细节 `message` 是实际交出去的那句话。
