# find — 在附近找东西

在附近找某种方块、生物或结构，找到的每一样给一个观察编号，可以直接拿它下达别的指令（"去那里""采掉它"）。只算看得见的：墙后面、埋在石头里的不算找到，但会说明搜了哪一片。刚放下的方块不会漏掉。一条末影龙是一条，不是九条。圈起来的、拴着的、有名字的生物照常报告，但会注明受保护。找不到时说清查了多大范围，不等于那里没有。

`block` / `blocks`、`entity`、`structure` 三选一，一次只找一种。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `block` | 三选一 | 找哪种方块（ID 或 `#` 标签） |
| `blocks` | 三选一 | 找哪几种方块（ID 或 `#` 标签） |
| `entity` | 三选一 | 找哪种实体（类型 ID，可给几种） |
| `structure` | 三选一 | 找哪种结构（命名空间 ID）；按记过的产地线索找，到附近还要亲眼确认 |
| `count` | | 要找到几个，找满即收工，默认 1 |
| `radius` | | 扫描半径，单位格；方块默认 48，实体默认 64；只扫已加载区 |

## 结果细节

| 字段 | 含义 |
| --- | --- |
| `found` | 命中列表，由近到远：观察编号 `id`、类型 `type`、位置 `position`、三维距离 `distance`、高低差 `dy`、方位 `direction` 与 `compass`；实体命中另有是否受保护 `creature_protected` 与原因 `protection_reason` |
| `searched_radius` | 实际查过的半径（格） |
| `search_complete` | 愿意找的范围扫完了没有 |
| `count_by_type` | 给了多种类型时，按类型分别找到几个 |

## 边界与注意

- 里程碑一只扫已加载区，找的时候不挪动角色：要搜更远的地方，先 travel 过去再 find。
- `structure` 按记过的产地线索找；没记过的线索会如实说这一片没有。跑图勘察还没有，属于后面的里程碑。
- 找群系不支持（要大范围跑图，随勘察能力一起来）。
- "查过已加载区没有"不等于"世界里没有"；没扫完时结果会写明。
- 受保护的生物（有名字、被驯服、拴着绳、圈养着）照常出现在结果里，但能不能动由许可决定。
