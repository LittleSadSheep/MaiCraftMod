# gather：采集

对世界里的一个东西做一次采集动作：收一株熟了的庄稼、挖一格方块、走近捡起地上的掉落物。
单点动作，薄能力——要"弄到 N 个"用 `obtain`，它会自己挑来源；`gather` 只对你指的那一个动手。

## 怎么做

1. 走到目标跟前，站位与靠近交给出行那一套，到不了会如实说试过哪些站位；
2. 看清现场：是熟了的庄稼就收，是普通方块就换够格的工具挖，工具不够格不会自己去备一把，
   而是结束并写清缺什么等级的工具——先用 `obtain` 备工具、再来 `gather`，两步都看得清；
3. 收完庄稼顺手把种子种回去：种子从这次收获里出，没有就不补，不额外去找；
   补种失败不会让已收的庄稼白收，进度照算；
4. 挖开后走近让游戏自己把掉落物收进包，归属由服务器结算；掉落物有拾取冷却，会照常等，不误报；
5. 拿没拿到按背包里同类数量的变化确认，挖了什么、捡到什么写进 `changes`。

动哪一格由 `permissions` 说了算：别人搭的、玩家放的，一格都不动。

## 结果怎么读

- `status`：`done` 采完；`failed` 没采成（问题里写清是缺工具、到不了、目标没了还是游戏拒绝）。
- `changes`：`block_broken` 挖掉了哪格；`item_gained` 捡到背包里的每样东西和数量——`item`
  只是用来确认的预期，实际掉什么按现场记录。
- 常见问题：`NEED_ITEM` 工具不够格（写清需要什么等级）；`TARGET_GONE` 那格已经不是要采的东西；
  `UNREACHABLE` 试过的站位都到不了；`WRONG_TIME` 庄稼还没熟（收了也白长，不收）。

## 参数

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `target` | ✅ | 目标对象：`seen` 观察编号（方块 b#、设施、掉落物 e#）或 `position` 加 `block` |
| `block` | | 配 `position` 目标用：要采的方块 ID；到了现场对不上会如实说 |
| `item` | | 认为会掉出的东西，用于确认；不给按实际掉落记录 |
| `radius` | | 捡掉落物时的范围（格）；拾取靠走近原版自动结算，这个范围是走近的容差 |
