# 工具等级与挖掘资格

方块有最低工具等级要求；等级不够时挖不动，或者挖碎了也不掉东西。

## 规则（镐类常撞项）

| 目标 | 最低镐等级 |
| --- | --- |
| 煤矿 minecraft:coal_ore、石头、圆石、下界石英矿 | 木镐 minecraft:wooden_pickaxe |
| 铜矿 minecraft:copper_ore、铁矿 minecraft:iron_ore、青金石矿 | 石镐 minecraft:stone_pickaxe |
| 金矿、红石矿、钻石矿 minecraft:diamond_ore、绿宝石矿 | 铁镐 minecraft:iron_pickaxe |
| 黑曜石 minecraft:obsidian、远古残骸 | 钻石镐 minecraft:diamond_pickaxe |

深层（深板岩）里的同种矿要求一样，只是挖得更慢。铁砧、熔炉这类石头或金属做的方块也要镐才会掉；斧、锹各有自己适用的方块，道理相同。

## 这个规则会怎么坑你

- 等级不够时要么挖得极慢（黑曜石几乎挖不动），要么碎了不掉——“挖了没掉”先对照这张表，再怀疑掉率或拾取。
- 下深处采矿前先确认身上有够格的镐，否则走下去了也只能空手回来。

## 在本 Mod 里

`maicraft:obtain` 缺够格的工具时会先去弄一把；`maicraft:gather` 只对指定的那一格动手，工具不够格会结束并写明缺什么等级的工具。细节看各自的能力说明。

## 边界

挖掘资格以手上工具的实际物品为准；本页不覆盖效率、时运、精准采集这些附魔对结果的影响。
