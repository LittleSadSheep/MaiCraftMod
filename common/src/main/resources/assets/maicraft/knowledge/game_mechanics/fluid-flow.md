# 流体流动与灌满

水（minecraft:water）与岩浆（minecraft:lava）会流动；流动的距离、方向和转化有固定规则。

## 规则

- 水从源头在平地上最多流 7 格，向下流动时距离重置；被挖开的坑和隧道会被**灌满**。
- 流动水遇到岩浆生成石头或圆石；水源直接接触岩浆生成黑曜石。
- 挖开海底、河床或含水地层下方的方块，水会灌进洞里；水下挖掘有明显减速。
- 岩浆同样是流体：挖掉隔挡方块，岩浆会灌进工作区（多数 HAZARD 类失败的真实来源）。
- 用桶收取液体要点在**源格**上——静止不流动、表面平整的格；流动中的水/岩浆无法被桶收取。

## 这个规则会怎么坑你

- 为自救倒水：水会沿刚挖开的隧道流进你所在的坑，把逃生空间灌掉——倒水前先确认流向与更低点在哪。
- 深挖接近含水层，隧道突然进水；站在流动水里会被冲离站位。
- 岩浆湖边采矿，隔挡一旦挖穿，损失的不只是通道还有掉落物。

## 边界

倒水、取水、引流后的成败以背包与世界实际状态确认为准；本页不预测具体流向，只提供"水会灌满挖开的空间"这一预期。
