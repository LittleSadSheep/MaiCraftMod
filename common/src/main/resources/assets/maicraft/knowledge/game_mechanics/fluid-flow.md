# 流体流动与灌满

水（minecraft:water）与岩浆（minecraft:lava）会流动；流多远、往哪流、碰到一起变成什么都有固定规则。

## 规则

- 水在平地上从源头最多流 7 格，往下流时重新计算距离；挖开的坑和隧道会被灌满。主世界的岩浆在平地上流得近（约 3 格），在下界和水一样远。
- 水碰到岩浆源头会把它变成黑曜石，碰到流动的岩浆会变成圆石；岩浆从上往下流到水上会变成石头。
- 挖开海底、河床或含水的地层，水会灌进洞里；人在水里挖东西明显变慢。
- 挖掉挡着岩浆的方块，岩浆会流进工作区，烧掉掉落物、点着角色。
- 桶只能舀源头那一格（不流动、表面平整的那格）；流动着的水或岩浆舀不起来。

## 这个规则会怎么坑你

- 倒水自救：水会顺着刚挖开的隧道流进你所在的坑，把逃生空间灌满——倒之前先看流向和更低的地方在哪。
- 深挖靠近含水层，隧道突然进水；站在流水里会被冲离原地。
- 岩浆湖边采矿，隔挡一旦挖穿，损失的不只是通道，还有地上的掉落物。

## 在本 Mod 里

舀水、倒水用 `maicraft:use` 拿桶对着那一格，细节看它的能力说明。

## 边界

倒水、舀水、引流之后的结果以背包与世界的实际状态为准；本页不预测具体流向，只提供“水会灌满挖开的空间”这一预期。
