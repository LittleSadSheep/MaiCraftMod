# 重力方块与塌落

砾石（minecraft:gravel）、沙子（minecraft:sand、minecraft:red_sand）、混凝土粉末、铁砧等是重力方块：下面空了就整列往下掉。

## 规则

- 挖掉一列重力方块最下面那块，上面同一列的会逐格落到最近的支撑面。
- 塌落会立刻改变地形：刚看到的方块挪了位置，挖好的通道被堵上。
- 落下的方块会盖住地上的掉落物；从高处掉下来砸到人会造成伤害，被埋住会窒息。

## 这个规则会怎么坑你

- 在砾石滩、河床、沙漠里挖，刚看到的方块塌走了、路一时走不通——这通常是暂时的：等方块落稳、重新看一眼现场再决定，不要当成彻底走不过去。
- 塌落可能把掉落物埋在新落的方块下面，出现“挖了没进包”。
- 站在砾石或沙柱下面挖它的支撑，会被整列砸中、埋住。

## 边界

塌落是真实发生的世界变化，本页只给出预期；塌了之后的现场以重新观察为准。
