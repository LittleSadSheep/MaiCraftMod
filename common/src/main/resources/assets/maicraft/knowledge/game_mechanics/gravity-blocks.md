# 重力方块与塌落

砾石（minecraft:gravel）、沙子（minecraft:sand、minecraft:red_sand）、混凝土粉末、沙锥等是重力方块：失去支撑后整列下落。

## 规则

- 挖掉一列重力方块的**下方**，上方所有同方块逐格塌落到最近支撑面。
- 塌落瞬间改变地形：寻路图失效、刚观察到的方块位置移动、坑道被埋。
- 落下的重力方块会掩埋地面掉落物，从高处坠落时还会造成伤害。

## 这个规则会怎么坑你

- 在砾石滩、河床、沙漠挖掘时，"刚确认的方块"塌走了，寻路报 no_path——这通常是**暂时的**：等方块落稳、重新感知即可，不是任务终态失败。
- 塌落可能把掉落物埋进新落的方块下方，出现"挖了但没进包"的确认差异。
- 站在砾石/沙柱下方挖它的支撑，会引来整列坠落砸中自己。

## 边界

塌落是真实世界事件，本页只提供机制预期；塌方后的现场以重新观察为准，"瞬时 no_path"不要直接当终态失败处理。
