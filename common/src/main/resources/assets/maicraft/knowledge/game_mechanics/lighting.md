# 挖掘工作面照明：黑暗即刷怪，光源是作业安全的一部分

## 规则

- 敌对生物在**方块光照为 0**的位置生成：夜晚地表与任何深度的地下黑暗区都会刷怪；光照等级大于 0 即压制刷怪，一支火把（光照 14，每格衰减 1）能护住半径十余格的工作面。
- 挖掘类任务的作业面（竖井、隧道、洞穴营地、深掘工作点）默认没有照明环节：任务不会自动插火把，模型必须在提交挖掘/下掘时想到照明，或事后主动补光。
- 火把随时可合成：煤/木炭 + 木棍 = 4 支。深掘前检查背包是否有煤与木料；有料不合成、合成不插放，都会把工作面留给刷怪。
- 照明的编排入口：`maicraft:auto_light`（自动补光）与 `maicraft:light_area`（发现语义区域边界、布光并验证覆盖）。两者都需要角色在场与火把原料；契约只读，不会替你决定何时该布光。
- 受伤模式识别：深洞内反复掉血、被骷髅箭击中、苦力怕爆炸，而任务回执只有失败或受伤事件——先检查工作面光照，再考虑装备与撤离。夜间远征的死亡多数与黑暗刷怪叠加。

## 这个规则会怎么坑你

- "任务回执没提照明" ≠ 不需要照明：挖掘契约不提醒布光，靠每次踩坑学会的代价是反复掉血与夜间死亡。
- 有煤有木料却在黑暗洞穴里被骷髅射到残血，是常见且可完全避免的损耗：合成火把并沿途插放，比治疗与跑尸便宜得多。
- 白天地表安全不等于地下安全：地下无天光，昼夜不影响洞内刷怪条件。

## 边界

- 光照只压制自然刷怪，不驱散已生成的怪；清怪仍走 `maicraft:combat` 或撤离。
- 布光能力不改变任何任务许可：插火把本身是改地形动作，受 `may_alter_terrain` 与保护名单约束。
