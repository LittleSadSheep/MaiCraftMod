# 照明与刷怪：黑暗就会刷怪

## 规则

- 敌对生物只在方块光照为 0 的地方生成：夜里的露天地面，以及任何深度、任何时间的地下黑暗处。方块光照大于 0 就压住了生成。
- 火把的光照是 14，离开一格减 1，一支火把能护住周围十来格；灯笼、萤石、海晶灯是 15。
- 火把 = 煤或木炭 + 木棍，一次合成 4 支；木炭用原木在熔炉里烧。
- 地下没有天光，白天和夜里一样黑。
- 光只阻止新的怪刷出来，不会赶走已经刷出来的怪。

## 这个规则会怎么坑你

- 在深洞里反复掉血、被骷髅射、被苦力怕炸，先想到工作面太黑，再考虑装备和撤离。
- 身上有煤有木棍却摸黑干活，被骷髅射到残血，是常见又完全能避免的损耗。
- 白天地面安全不等于地下安全。

## 在本 Mod 里

角色还没有专门补光的能力；清已经刷出来的怪用 `maicraft:fight`，细节看它的能力说明。

## 边界

本页只讲刷怪与光照的原版规则；实际亮不亮、有没有怪，以现场观察为准。
