# mine 源查询的公平语义与探矿许可（可见范围、生成带与保留意见）

acquire_items 的 mine 源族从**即时可见或先前见过的源**开始；不会从区块索引直接瞄准未知埋藏矿。安装 FTB Ultimine 且原生允许时，可以沿服务器实际展示的完整矿脉选区连锁采集，包括相连的埋藏矿。需要主动开路找矿时使用 `allow_prospecting`。

## 规则

- 候选源必须过公平闸：**即时可见 ∨ 观察记忆里见过**。见过一次的位置会被记住（随世界状态持久），之后重新被遮挡仍可挖；从未见过的埋藏矿不进目标集。
- 公平扫描空手时，结果是诚实的"范围内无可用源"，且不泄露被遮挡候选的数量、位置或存在暗示——没看到就没有这份数据。
- 原生整脉选区中的每格仍须属于请求材料和搜索范围，并遵守明确保护、工具与原生限制。预览不是完成证明：原生可能只挖掉部分选区，任务核对实际方块和背包变化后继续。FTB 把整批掉落集中在触发块，采矿会在那里收取。
- `allow_prospecting=true`（默认 false）：公平扫描空手后，向该物品的**已知自然生成带**开路，目标层按就近选取：当前位置已在带内就取当前层水平掘进（煤这类全域矿不强制移动高度），带上方取带顶、带下方取带底；每条带还记有暴露率峰值层（钻石 -59、铁 16、铜 48、煤 96），窄带矿的就近层与峰值层基本重合。到层后沿水平方向找矿。下降使用 FTB 原生 `mining_tunnel`，水平使用 `small_tunnel`；方向取实际命中面，竖向点击的下降形状沿角色水平朝向。
- 生成带查询同时识别**矿方块 ID**与**产物物品 ID**：`minecraft:iron_ore`、`minecraft:deepslate_iron_ore` 与 `minecraft:raw_iron`、`minecraft:iron_ingot` 落到同一条铁带。用方块名说"挖这种矿"与用产物名说"要这种料"都有效； stone、dirt 等普通方块与表外物品一样被如实拒绝。
- 正常角色下降阶梯需要三格通行高度，水平通道需要两格；这是角色扫过的空间条件，不是固定挖三次或两次。原生线段遇矿物或不同材料中断后，重新选择剩余障碍与命中面补齐，完整断面和实底连续成立后才行走。没有原生连锁、选区超出许可或余量不足时，松开连锁键再逐格补齐。
- 表内没有该物品、或生成带在另一个维度时，探矿**如实拒绝**：没有生成带证据就猜一个下降深度，等于把透视伪装成探索。许可打开但探不成的结果会写明原因。
- 接近源允许动土（默认开启）：挖掘目标在抬高的地形上时，接近阶段会挖阶梯、挖隧道或垫高柱凑近，而不是直接判无路。`may_alter_terrain=false` 才收窄回普通行走路线；这只收窄通道，不改变目标筛选，禁挖名单与保护名单照常生效。
- 未许可（默认）：维持公平空手行为，不下降也不掘进——想要"挖着找"必须在同一次提交里带上许可位。

## 这个规则会怎么坑你

- 把"公平扫描空手"误读为"世界上没有这种矿"：它只覆盖已加载且过闸的范围；未加载区块与更深地层不构成"不存在"的证据，扩半径、换位或开探矿都可能改变结果。
- 地表提交 `acquire diamond` 不带许可，会得到诚实的空手结果——深层矿从未进过你的视野，也不该有；带 `allow_prospecting=true` 重新提交才走下降加掘进。
- 从地表直接 acquire 深层矿带物品（钻石、深层铁）报 mined_out 是**正常预期**：查询只在站立位置下方约 25-30 格内收敛，不构成"世界里没有"的证据——先按生成带下降到矿带高度再查询，或一次提交就带上 allow_prospecting 让任务自己下降。
- 许可不是深度参数：模型无法指定"挖到 y40"；若目标物品没有已知生成带（表外物品），探矿会拒绝而不是照挖。
- `find_block` 的命中坐标是通过当前眼位射线确认的观察，可按实际能力字段交给 travel、harvest_block 或 interact。当前查块任务不会把它写入 mine 的观察记忆；自动采矿仍要通过自己的可见性或已有记忆检查。定点采收必须带匹配的 block_id、expected_output_item_id 与单格 may_alter_terrain=true，来源还须在执行时满足已加载、非空气、无流体状态及无方块实体等条件。
- mine 结果报"no route to any of the N verified targets"时另有两种可能混在"没挖到"里：一是目标确实走不到（这时接近性动土已在尝试挖路仍失败，考虑 travel 接近后再挖）；二是天然原木场景里还有候选没通过树形检查、从未被当作目标（失败文本会点名数量，那不是"它们不存在"的证据）。两种出路不同，先读失败文本再决定。

## 边界

就绪语义不变：观察快照 `query_complete: false` 时索引尚未就绪，不得得出"范围内无源"的结论；结果携带扫描中心、半径和索引就绪状态。`ultimine_actions` 完整保留原生选区的实际变化、未挖格及未知项；`prospecting.blocks_dug` 单独统计开路方块，材料完成数量仍按实际背包增量。预算包含下降断面和到层后的水平开路，耗尽时如实停止，不虚构剩余储量。
