# 往下挖与地下通行

## 规则

- 不要垂直往下挖脚下那一格：下面可能是洞穴、岩浆湖或深坑，一挖穿就掉下去。
- 阶梯式往下挖（每往下一格也往前一格）最稳：随时能沿着台阶走回去，前面有什么也看得见。
- 人要两格高的空间才走得过去；疾跑跳跃要三格。
- 挖头顶上的砾石、沙子会塌下来砸人、埋人（见重力方块那一篇）；挖穿水或岩浆的隔挡会被灌（见流体那一篇）。
- 地下容易迷路：进矿洞前记住入口在哪。

## 这个规则会怎么坑你

- 站在自己挖的竖井底继续往下挖，最容易掉进洞里或岩浆里，也最难爬回去。
- 同样的办法原样再试一次，通常得到同样的结果；换个形状（阶梯、水平通道）或换个位置才有用。

## 在本 Mod 里

- `maicraft:travel` 默认可以挖开天然方块、垫临时方块开路，去某个高度就给带 y 的坐标；能不能动方块由许可管。
- 记下矿洞入口用 `maicraft:remember`，回来时按地点名走。
- 细节看各自的能力说明。

## 边界

本页只讲往下挖和地下走路的常识；走没走到、卡在哪，以出行的结果为准。
