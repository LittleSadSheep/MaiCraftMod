# mine 源查询的范围语义（半径、深度与保留意见）

acquire_items 的 mine 源族从**已加载区块**中查询"当前工具可采"的暴露源；查询有明确的范围与就绪语义。

## 规则

- 查询完成后（`query_complete: true`）回执携带扫描中心、chunk 半径与 `known_sources` 计数；**范围外、未加载区块与更深地层不构成"不存在"的证据**。
- 查询只认**已暴露**的源：埋藏在覆盖层后的矿不会被挖掘编排向内掘进——mine 不为埋藏目标挖隧道。
- 深层矿（从地表看 y16 以下的钻石层）：先用 travel(exact, may_alter_terrain) 下降到目标高度附近再提交采集；站在地表直接采集深层矿会得到诚实的"范围内无源"判定。
- 失败回执给出三条出路：扩大 radius、换位接近、用 find_block 定位后再采集。

## 这个规则会怎么坑你

- 把"范围内无源"误读为"世界上没有矿"：它的含义是"这个扫描范围内没有"，换位、扩半径、先下降都可能改变结果。
- 已知坐标的埋藏矿脉：mine 不会挖开覆盖层，要么 harvest_block 单点采集（需已观察），要么 travel 清障开路。
- 观察快照里 `query_complete: false` 时索引尚未就绪，此时尚不能下"没有源"的结论。

## 边界

就绪语义（025 已修）：查询未完成不得产出 mined_out 终态；范围声明（扫描中心/半径/未加载计数）强制随回执携带。
