# 世界刻速与失焦：任务变慢先想到它

## 规则

- 游戏世界正常每秒推进 20 刻；单人游戏的世界就跑在这台电脑上。
- 游戏窗口失去焦点时：开着“失去焦点时暂停”会弹出暂停菜单，单人世界整个停住；关着时，系统可能给后台窗口限速，世界会明显变慢，可能一秒推进不到 1 刻。
- 世界慢下来时，角色、怪、熔炉、作物都一起慢；这是运行环境的问题，不是任务出了故障。窗口回到前台就恢复。

## 这个规则会怎么坑你

- 任务好久没进展、角色也没怎么动，直接取消重下：重下之后世界还是一样慢，前面的进度反而白费了。
- 把世界变慢说成“游戏卡死了”：这时画面看起来可能仍是正常速度，也可能停在一个暂停菜单上。

## 在本 Mod 里

任务进展异常地慢时，先等一会儿再看一次任务和角色，变化跟时间对不上就是世界变慢了；需要时请把游戏窗口切回前台，或让操作这台电脑的人切回前台。

## 边界

本页只说明世界变慢的常见原因；角色具体卡在哪，以任务结果和现场观察为准。
