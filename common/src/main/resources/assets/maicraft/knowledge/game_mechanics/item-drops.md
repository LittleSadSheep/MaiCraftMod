# 掉落物：拾取半径、漂走与消失

挖碎方块、打死生物掉出来的东西是地上单独的物品实体，不会直接进背包。

## 规则

- 拾取半径约 1 格：人走到物品跟前，它才会进背包；背包满了捡不起来。
- 掉落物受重力往下掉，会顺着水流漂走、被活塞推走，可能掉进洞里、被塌落的方块埋住，掉进岩浆或碰到仙人掌会被烧毁。
- 掉落物在地上大约 5 分钟后永久消失。
- 刚掉出来的东西有一小段拾取冷却，马上走过去也要等一会儿才进包。

## 这个规则会怎么坑你

- “方块确认挖碎了，东西没进包”有几种可能：没走到 1 格以内 / 背包满了 / 漂走或被埋了 / 已经消失。排查顺序：先看背包有没有空位 → 走近再看一眼周围 → 最后才想到消失。
- 在水边或斜坡上挖，掉落物常会滚走、漂走；挖完站到掉落的地方最稳。
- 掉落物所在的那格不一定能站人；站在旁边一格、只要够得着也能捡到。

## 在本 Mod 里

- `maicraft:gather` 挖碎方块后会走近让游戏把东西收进背包；地上已有的一堆，可以用观察里它的编号当目标让它去捡。
- `maicraft:fight` 打赢后会就地捡一下掉落物。
- 具体用法看各自的能力说明。

## 边界

拿没拿到以背包里实际多出来的为准。
