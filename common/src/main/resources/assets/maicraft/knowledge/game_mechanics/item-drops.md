# 掉落物物理：拾取半径、漂移与消失

破坏方块或生物死亡产生的掉落物（item entity）是独立实体，不会即时进入背包。

## 规则

- 拾取半径约 1 格：掉落物进入玩家附近才会入包。
- 掉落物受重力下落、随水漂移、可被活塞推动，可能落进洞里或被塌方掩埋。
- 掉落物有约 **5 分钟的消失计时**，超时永久消失。

## 这个规则会怎么坑你

- "方块确认破坏但物品未入包"有三种可能：没走到拾取半径内 / 掉落物漂走或被埋 / 已消失。排查顺序：先看回执 `remaining_live_drops`（仍留在地上的归属掉落物清单）→ 走近再观察 → 最后才考虑消失。
- 水边或斜坡挖矿，掉落物常滚走；挖完后站到掉落位置 1 格内最稳。
- 深坑挖矿，掉落物掉进更深的洞里，站在坑沿是捡不到的。

## 边界

对账以背包净变化为准；回执的 gathered 声明与背包对账矛盾时，以背包为准并如实上报差异。
