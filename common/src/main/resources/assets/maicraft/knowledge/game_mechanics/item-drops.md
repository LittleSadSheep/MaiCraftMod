# 掉落物物理：拾取半径、漂移与消失

破坏方块或生物死亡产生的掉落物（item entity）是独立实体，不会即时进入背包。

## 规则

- 拾取半径约 1 格：掉落物进入玩家附近才会入包。
- 掉落物受重力下落、随水漂移、可被活塞推动，可能落进洞里或被塌方掩埋。
- 掉落物有约 **5 分钟的消失计时**，超时永久消失。

## 这个规则会怎么坑你

- "方块确认破坏但物品未入包"有三种可能：没走到拾取半径内 / 掉落物漂走或被埋 / 已消失。排查顺序：先看结果 `remaining_live_drops`（仍留在地上的归属掉落物清单）→ 走近再观察 → 最后才考虑消失。
- 水边或斜坡挖矿，掉落物常滚走；挖完后站到掉落位置 1 格内最稳。
- 掉落格本身不一定能站人。只要角色仍能接触物品，站在坑沿或邻格也能拾取；任务会按实际接触范围选站位。
- 补拾取用 `maicraft:collect_items`，可传 `nearby_entities` 中的 `drop_ref` 精确指定一堆。已获准为拾取开路时，带 `may_alter_terrain=true`；任务会在同一任务中补齐脚位、头顶等通行缺口，再走近收取，不需要额外串联 travel 和挖块任务。
- 开路仍遵守清障名单及保护范围，默认未许可时只走现有通道。结果 `pickup_navigation` 保留本次许可和确认挖放的全部位置，`drop_collection` 保留目标引用、现场观察和未收取部分。

## 边界

确认以背包净变化为准；结果的 gathered 声明与背包确认矛盾时，以背包为准并如实上报差异。
