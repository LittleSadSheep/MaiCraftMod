# 睡眠与夜晚：刷怪、床与跳夜

## 规则

- 敌对生物在方块光照为 0 的地方生成：夜里的露天地面和任何时候的地下黑暗处都会刷怪；照亮就能压住周边的生成（见照明那一篇）。
- 夜里的怪成群出现：僵尸近战加骷髅远程，几轮就能把没穿护甲的角色从满血打到濒死；水边还有溺尸。
- 床：3 块同色羊毛 + 3 块木板合成。夜里或雷雨时能睡，睡一觉跳到天亮，并把重生点设到床边；附近有敌对生物时睡不着，要先清掉或躲进封闭处。下界和末地里用床会爆炸。
- 羊毛：剪刀剪羊得 1 到 3 块、羊不死；打死羊掉 1 块。羊毛颜色和羊一样；颜色不齐时可以用染料先把羊染成同一种颜色再剪。
- 幻翼：连续 3 个游戏日以上没睡过觉，夜里会刷出幻翼从天上俯冲攻击，睡过一次才停。

## 这个规则会怎么坑你

- 连着几天不睡，幻翼的俯冲加上摔落伤害，常常还没反应过来就死了。
- 床要 3 块同色羊毛；白、灰、棕各一块合不出床。
- 附近有怪时睡不着；睡前先清怪或进封闭的屋子。
- 夜里没有护甲和武器在外面跑图代价很高；开局先把食物、床和据点立住再往外走。

## 在本 Mod 里

- 角色还没有睡觉的能力。到了能睡的时候，角色在安全的地方或打得过周围的怪就接着干活；露天又打不过时，会自己就地挖坑封顶熬到天亮——这是生存需求，不用专门下达。
- 想等到天亮或天黑再做事，用 `maicraft:wait`；剪羊毛用 `maicraft:use` 拿剪刀对着羊。细节看各自的能力说明。

## 边界

- 睡觉跳夜是原版机制；在聊天里发 /time set day 这类命令是另一回事，两者不要混为一谈。
- 吃饭与饥饿看食物那一篇。
