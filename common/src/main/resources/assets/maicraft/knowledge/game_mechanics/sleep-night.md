# 睡眠与夜晚：刷怪、床与跳夜

## 规则

- 敌对生物在方块光照为 0 的地方生成：夜里的露天地面和任何时候的地下黑暗处都会刷怪；照亮就能压住周边的生成（见照明那一篇）。
- 夜里的怪成群出现：僵尸近战加骷髅远程，几轮就能把没穿护甲的角色从满血打到濒死；水边还有溺尸。
- 床：3 块同色羊毛 + 3 块木板合成。夜里或雷雨时能睡，睡一觉跳到天亮，并把重生点设到床边；附近有敌对生物时睡不着，要先清掉或躲进封闭处。下界和末地里用床会爆炸。
- 羊毛：剪刀剪羊得 1 到 3 块、羊不死；打死羊掉 1 块。羊毛颜色和羊一样；颜色不齐时可以用染料先把羊染成同一种颜色再剪。
- 幻翼：连续 3 个游戏日以上没睡过觉，夜里会刷出幻翼从天上俯冲攻击，睡过一次才停。

## 这个规则会怎么坑你

- 连着几天不睡，幻翼的俯冲加上摔落伤害，常常还没反应过来就死了。
- 床要 3 块同色羊毛；白、灰、棕各一块合不出床。
- 附近有怪时睡不着；睡前先清怪或进封闭的屋子。
- 夜里没有护甲和武器在外面跑图代价很高；开局先把食物、床和据点立住再往外走。

## 在本 Mod 里

- 夜里睡觉不用专门下达：天黑后只要今晚有床（附近有能用的床，或身上带着床），角色会在手上的活到了两个动作之间、或闲着的时候自己去睡；睡醒收回自己放下的床，再回到原来的位置接着干。放在用 `maicraft:remember` 记成"家"的地方附近的床不收，留着当重生点。
- 自己去睡只用现成的床，不会去做床。没床时看处境：在屋里、矿道这类安全的地方，或者打得过周围的怪，就接着干活；只有露天又打不过，才就地往下挖三格、把头顶封上（挖三填一）熬到天亮。
- 想让角色夜里睡上床，用 `maicraft:sleep`：附近没床时它会放下身上带的床，或者现做一张。白天调它也不会干等：先把今晚的床备好，再报告"现在睡不了"，天黑后角色自己去睡。
- 过夜不要用 `maicraft:wait` 原地等天亮；没床就先去弄床，或者在安全的地方接着干活。`wait` 只用在"等到天亮或天黑再做某件事"这类确实要卡时间的地方。
- 剪羊毛用 `maicraft:use` 拿剪刀对着羊。细节看各自的能力说明。

## 边界

- 睡觉跳夜是原版机制；在聊天里发 /time set day 这类命令是另一回事，两者不要混为一谈。
- 吃饭与饥饿看食物那一篇。
