# 睡眠与夜晚：刷怪、床与跳夜

## 规则

- 敌对生物在黑暗处生成：白天靠天光的地表安全，夜晚与地下黑暗区会刷怪；插火把等光源照明可压制周边生成。
- 夜间怪物组合强度：僵尸近战 + 骷髅远程的组合可以在数轮攻击内把无护甲角色从满血打到濒死；水边另有溺尸。
- 床：3 个**同色**羊毛 + 3 块木板合成；夜间使用床直接跳到天亮，并把重生点重设到床的位置；附近有敌怪时无法入睡，需先清怪。
- 羊毛与颜色：羊掉落的羊毛与羊本身同色；`maicraft:find_entity` 与 `maicraft:combat` 支持按 `sheep_color` 筛选羊（原版 16 色名），指定颜色取羊毛时会自动排除幼羊和已剪毛的羊；异色羊毛也可以用染料染色统一（把羊染成目标色再剪/杀更省）。
- 幻翼：连续 3 个游戏日不睡觉，之后每夜会生成幻翼俯冲攻击，直到睡过一次才停止。
- 本 mod 出路：`maicraft:sleep` 能力会寻找或放置可用床并躺下睡觉——夜里不必硬熬。

## 这个规则会怎么坑你

- 连续几天不睡，幻翼夜间俯冲叠加上坠落伤害，常在反应过来之前致死。
- 床配方要求同色 3 羊毛；白/灰/棕各一的羊毛合不出床——用 `sheep_color` 筛选猎同色羊，或用染料把羊毛统一颜色。
- 附近有敌怪时入睡被拒绝；睡前先清怪或进掩体。
- 夜间无护甲无武器外出跑图代价极高；开局阶段建议先把"食物来源 → 床 → 基地"三件基础设施立住再推主线。

## 边界

- 睡觉跳夜是原版机制；chat 通道的服务器指令（如 /time set day）是另一条作弊通道，两者不要混。
- 进食与饥饿规则见食物卡。
