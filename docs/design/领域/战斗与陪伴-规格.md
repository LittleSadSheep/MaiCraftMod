# 领域规格：战斗与陪伴

> 状态：执行侧按第 10 节建议拍板执行中（2026-10-09 用户授权先干后改，所有者可推翻后修正实现）。
> 范围：能力 `fight`（基础：打指定目标、清一片区域的敌怪）、`follow`（跟随）、`wait`（在游戏里等一个条件），加上生存需求里的饥饿、夜晚、被攻击、贴边与威胁评估；饥饿驱动的临时吃饭任务在本域正式设计，只组合 `eat`，不重写它。
> 依据：战斗与生存需求旧逻辑清单（117 条，v0 `dev`，`aa97940c9`）。
> 边界：入睡本体与选床归睡觉规格（已由睡觉试点覆盖，本规格在夜晚需求处只做触发与分流，不重复设计）；进食执行（`eat` 能力）归吃穿与背包规格；随行补光归建造与照明域，里程碑一不做；末影龙、玩家对战、末影水晶的专门打法不在里程碑一，由 LLM 按攻略规划。
> 说明：第 5 节"位置"都指 v0（`dev` 分支）的文件；v1 按本规格重写，不移植这些文件。打断的通用机制（多快必须处理、此刻能不能打断、控制循环怎么压栈）已定，本规格只写各生存需求怎么报急、临时任务怎么插进主任务。

## 2 真人怎么做

打架：看清楚要打谁。打得过就上，用手上最顺手的家伙——有弩用弩，有弓有箭就拉开距离射，都没有就抄剑；对面举盾就换斧头。一群怪里先对付最近的、最危险的（点了引信的苦力怕最急）。打着打着血见底、护甲快碎了，或者对面根本打不过，就跑：甩开所有追着的，跑到没人追了再说；跑了就是没打赢，不会把"逃出来了"说成"打完了"。打死了就地捡一下掉落物，捡不到也就算了。赤手空拳对面还会还手的，不主动凑上去。

被偷袭：谁打我还谁。要是边干活边被咬，先把它解决掉再回来接着干，解决完回到原地，东西不会自己挪走。血掉得厉害还在挨打，先撤，不硬拼。

吃饭与过夜：饿了趁干活的间隙掏点吃的；身上没吃的，去弄点来（翻箱子、做、采，别为了一口饭跑半个地图）；实在弄不到就跟人说一声，继续干活，不会饿着肚子站着发呆。天黑了附近有床就去睡；弄不到床，处在安全地方或打得过就接着干，露天又打不过才挖个坑把自己封起来熬到天亮。

陪伴与等待：让跟着谁，就保持几格距离跟着走，人家停我也停；跟丢了或者路走不通就说跟不上了，不会自己跑去别处找人。让等到天黑、等血回满，就站在那儿看着，等到了说一声；等不到就一直等，不会自作主张去把条件"做"出来——等血回满不等于自己去吃东西。

## 3 新逻辑

### 3.1 fight（打指定目标，或清一片区域的敌怪）

```text
0 已满足     点名的目标已确认死亡 → 直接完成，写"开始时已被击败"
1 校验       许可由 permissions.fight 决定能打谁（M7）：self_defense 只还手，hostile_mobs 只打
             敌对生物，any 才能打点名的其他目标；LLM 明确点名的观察编号本身构成对它的许可。
             候选一律过滤掉保护对象：玩家、驯服的、有名字的、围栏里的（M7 保护判断，全仓一份）
2 选目标     target 指定（seen e#）→ 只打它，几个编号逐个来
             省略 target → 只清 radius 内的敌对生物，按威胁排序（近处苦力怕优先），
             count 是最多处理几只；不探索、不去远处找目标
3 评估       ThreatAssessment（3.4）：能赢 → 打；有风险 → 打但保持在远程距离带；
             打不过 → 不开打，以 DANGER 结束，写明差在哪（血、武器、数量）与怎样能继续
4 打         每刻：扫战场（危险半径内的威胁）→ 决定走位 / 近战 / 弓弩 / 撤离 / 完成；
             一场战斗内盯住同一目标，不每刻重选；武器从背包挑：已上弦弩 > 有箭弓 > 剑斧 > 空手，
             对手举盾优先斧；站位交给 M2，出手是原生攻击、由 M3 逐刻确认（攻击充能够格才挥）
5 撤离       打不过或血量跌破拒战线（护甲折算后的有效血量线）→ 撤：
             甩开所有参与了追击的和新近出现的危险，跑到逃跑判定距离之外；
             撤离成功不等于任务成功：目标没击败就以 failed 结束，problem 写明拒战线与出路
             （吃什么能回血、回多少血能再战）；期间退路连续寻路失败、又确实走不出两格，才算背水一战
6 拾荒       目标死亡确认后，捡身边的掉落物；够不着、被抢、消失 → 写进结果，不影响击败判定
7 结算       changes 记击败（实体死亡证据）与拾取（物品入包）；
             details 见第 4 节；战斗被生存需求打断再回来，进度不丢（临时任务压栈）
```

组合的模型：M2（走位与换位）、M3（攻击提交与确认）、M4（弓箭与武器的身上来源）、M6（被打攻击时的自卫临时任务就是本能力的一个无差别实例）、M7（许可与保护）、M8（进度、撤离重试、结果）、M12（观察编号、威胁扫描）。

本能力特有的部分：武器挑选、威胁排序、拒战线与撤离、拾荒。

### 3.2 follow（跟随）

```text
0 语义       跟随是常驻任务：走到距离内后停住保持，没有"完成"；
             只有目标丢失、路线走不通或 LLM 取消才结束
1 找目标     target 必填（player 或 seen e#）；用实体的真实身份核对，
             编号被重用给了别的东西 → 判目标丢失，不跟着新实体走
2 跟        走出 distance+2 才起步，回到 distance 内就停（迟滞防抖，不在临界距离一步一停）；
             要不要为跟进而搭桥挖路，由 permissions.change_blocks 表达，默认不改世界；
             目标悬空时寻路锚取它脚下的地面，停止判断仍按实体本体的三维距离
3 结束      目标消失 → TARGET_GONE（写明最后看到它的方位）；路线不通 → UNREACHABLE，
             附"允许改哪些方块就能过去"的说明
```

本能力特有的部分：距离迟滞与目标身份核对；其余全是 M2 / M10 / M12。

### 3.3 wait（等一个条件）

```text
1 参数       condition（默认 elapsed）+ after_seconds（可选，最短先等这么多秒）；
             非法取值在参数校验阶段拒绝，一次报全
2 等         先过 after_seconds（从任务开始那刻起算；普通暂停承认已过去的时间），
             再逐刻检查条件；不成立就继续等，没有超时——等待只观察，不替角色达成条件
             （等血回满不会自己去吃东西、改时间）
3 完成       条件成立即结束，写明实际经过了多久
```

本能力特有的部分：五种条件的读法（时间相位、生命、饥饿）；其余是 M8。

### 3.4 威胁评估（纯函数，`behavior.survival` 提供，全仓一份）

```text
我方   生命、按护甲折算的有效血量、武器伤害排序、食物储备、有没有退路
对方   数量、种类（近战 / 远程 / 爆炸 / 飞行）、是否正在追我、距离、引信状态
地形   会不会被包围、能不能卡位、附近有没有岩浆或悬崖
结论   能赢 / 有风险 / 打不过
```

它被三处消费：被攻击时还手还是撤离（本域）；床边有怪时清怪还是带床换地方（睡觉规格）；夜里露天要不要躲（本域夜晚需求）。"想不想打"由 `permissions.fight` 表达，评估只回答"打得过打不过"。

### 3.5 生存需求：报急与临时任务

每项需求每刻算一次多快必须处理，需要动手时由它创建临时任务，插不插得进去由打断规则与控制循环决定（NOW 打断一切；SOON 不打断"停下不安全"的任务；LATER 只在两个动作之间插入）。被插进去期间主任务的进度不计时。这里只写各需求自己的触发、处理与收尾。

**报急的统一走法**：自己能处理 → 建临时任务，做完结束，主任务从原地继续；自己处理不了（身上没吃的、弄不到床、搜不到透气的口、围困格受保护）→ 临时任务立即结束，发一条任务事件把事实告诉 LLM（缺什么、试过什么、主任务没受影响），同时 `observe(self)` 里一直能看到。临时任务的开始、结束、转交都发任务事件。

**饥饿**：身上最小的一件普通食物能整份补进去（饱食度加它的营养不超过 20）→ LATER，饱食度刚掉一两格不为它停下手上的活；低于等于 6（不能疾跑）→ SOON；0 且在掉血 → NOW。
临时吃饭任务：在身上找食物，与 `eat` 能力共用挑食物的规则（`FoodPicker`），但饿了顺手吃挑得更省：只吃无效果、饱腹时不能吃的普通食物（金苹果、紫颂果、腐肉都不动），按饱食度还差多少挑补得刚好的；饱食度见底已在掉血才按 `eat` 的顺序什么都吃。一次插进来只吃一口，还饿由下一次报急再插——本任务只组合吃一口的原生动作，不重写进食。身上没吃的且已到 SOON → 建一个有预算的弄吃的临时任务（M4：翻随身背包与已知容器、合成、采集，只弄"能直接吃的"），弄到就吃，弄不到 → 结束并报急。随身口粮储备持续偏低 → 不立刻催，等出现饥饿迹象（真的饿过、或在吃腐肉充饥）才发一条建议性事件（"建议建立食物供给"）；刚吃完一口不催，刚出生没饿过也不催。

**夜晚**：到了可以睡的时间 → LATER，能弄到床（现成的、自带的、现做的）→ 插入夜间休息临时任务，入睡、选床、睡醒回站位全按睡觉规格执行，本域只负责"什么时候插、主任务在两个动作之间时才插"。弄不到床：身处安全处（地下矿道、屋里、照明充足）或威胁评估不是"打不过" → 继续干活，不插；露天、敌怪多、评估为打不过（或生命低、没护甲）→ SOON，插入极端自保：挖三填一，封自己到天亮或威胁解除。这一条与睡觉规格的取向一致，本域只做触发与分流。

**被攻击**：有敌对生物正在攻击自己（含 10 秒内真打过我的、锁定我的、近处膨胀的苦力怕）→ SOON，插入自卫临时任务；生命跌破拒战线且仍在挨打 → NOW，先撤离再谈别的。自卫临时任务是 fight 的一个无差别实例：不按名单，谁构成威胁打谁（会分裂的怪裂开后新个体天然在威胁集里）；不追离开打点太远（只比水平距离），撤退和躲爆炸不受这个限制；危险消失后再观察一小段（跑得几乎一样快的怪会在边界上一进一出，不撒手太早）；收尾时离开打点太远就以步行速度走回去再交还，走不回去 → 暂停主任务并发事件说明停在了哪里。主任务本身就是 fight 且威胁评估不是"打不过"时，自卫不插入（有人正在替这条本能干活）；血线破了则只有本能说了算，自卫接管。开始与结束时发事件：打点、位移、红心差、暂停了哪个任务。

**贴边**：站在深落差的边缘、重心贴着边 → LATER，只在身体被放开时（手上没有任务管身体、角色闲着）退回安全处。在岗任务把身体留在边缘是正当姿态（建筑贴墙、钓鱼、寻路贴崖、搭桥），有任务时一律不退——在两个动作之间退一步、任务又走回边上，只会来回抖。退回的落点要脚下踩得住、不是另一道深落差，附近找不到（四面是崖的独柱）就不退。

**坠落、溺水、被埋、着火**：触发阈值与 NOW 等级已定，本规格把这些旧链里的判断细节（第 5、7 节）归进对应判断类与临时任务：换气有水下呼吸类效果就不触发、空气按上浮用量算预算、头顶封闭时按水下路线搜到开口再上浮、搜不到立即报受困；坠落自救按落点介质取消（落进深水水本身就是缓冲，入水立即收尾并如实记录）；被埋按眼位格与头位格任一致窒判定，只挖致窒的那一格，超时或受保护如实报告；换气期间有近身攻击者先反击，逃生输入不被清掉。

### 3.6 寻死

明确的寻死任务通过 `permissions.survival_needs = off` 关掉全部生存需求，不在打断规则里开后门；任务暂停或结束后需求恢复。护甲穿回这类寻死配套动作归寻死能力自身。

## 4 能力说明（参数与结果）

三个能力都接受可选的 `permissions`（按 M7）；fight 的许可字段是 `fight`，follow 间接用到 `change_blocks`。

### maicraft:fight

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| target | | `seen`（e#，可多个）；省略时清 `radius` 内的敌对生物 |
| `entity` | | 只清这种实体类型（区域清扫时的过滤）；省略即全部敌对生物 |
| `radius` | | 区域清扫的范围，单位格（默认 32） |
| `count` | | 区域清扫时最多处理几只；省略即区域内全部 |

能力说明：

> 打指定的目标，或清掉附近一片区域的敌对生物。先评估打不打得过：打不过会直接说差什么，不会白白送死。打得过就上，武器自己挑，血见底会先撤离，撤离了不冒充打赢。击败后就地捡一下掉落物，捡不到也会如实说明。玩家、别人的宠物、有名字的动物不在清扫范围内；要点名打它们需要放开许可。

本能力特有的结果细节：

| 字段 | 含义 |
| --- | --- |
| `defeated` | 确认击败的目标（死亡证据） |
| `fled` | 是否以撤离收场（此时 status 为 failed，目标没死） |
| `threat_verdict` | 开打前的威胁评估结论：能赢 / 有风险 / 打不过 |
| `weapon_used` | 实际用的武器 |
| `loot_gained` | 拾荒捡到的物品与数量 |

### maicraft:follow

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| target | ✅ | `player`（一位玩家）或 `seen`（e#） |
| `distance` | | 保持的距离，单位格（默认 3，2..16） |

能力说明：

> 跟着一位玩家或一个实体，保持几格距离：它走就跟，它停就停。跟随是常驻的，不会自己结束；要停下用 task 取消。目标消失或路走不通会结束并说明原因。跟随不包含保护它、帮它打架或跨维度找回。

本能力特有的结果细节：

| 字段 | 含义 |
| --- | --- |
| `target_id` | 跟的是谁（身份与类型） |
| `kept_distance` | 结束时与目标的距离 |

### maicraft:wait

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `condition` | | 等什么：`elapsed`（只等时间，默认）/ `day` / `night` / `health_full` / `not_hungry` |
| `after_seconds` | | 最短先等多少秒再开始查条件（0..3600，默认 0） |

能力说明：

> 在游戏里等一个条件：等到天黑或天亮、等生命回满、等不再饥饿，或单纯等一段时间。只观察，不会为了达成条件去做任何事。没有超时，等不到会一直等；要设上限或中途停下，用 task 取消。

本能力特有的结果细节：

| 字段 | 含义 |
| --- | --- |
| `waited_seconds` | 实际经过的秒数 |
| `condition_met` | 成立的那个条件 |

## 5 旧逻辑归类表

类别：F 游戏事实 / C 玩家常识 / P 补丁 / G 预判拦截 / S 过严或无意义。去向四种：**保留**（内容延续，只换位置）、**重写**（机制由模型或接口取代后重新实现）、**丢弃**（不再存在）、**移交**（归姊妹领域的规格，本规格不重复定做法）。清单原有的类别建议已逐条复核；改判处写明理由。

### 5.1 战斗目标与许可（适配层）

| 编号 | 位置 | 内容 | 类别 | 去向 |

## 9 验收

**离线场景测试**（判断类用替身接口，任务用动作替身，不使用 `Unsafe`）：

1. 威胁评估：重甲与裸奔同血量不同结论；无武器且对面会还手 → 打不过；退无可退时改判背水一战；点着引信的苦力怕排序最前；会炸且无远程的不进候选；上一刻的目标仍可打就保持。
2. fight 目标：点名保护对象需放开许可；省略 target 按威胁排序清区域且受 count 上限；区域外与未加载不探索。
3. fight 结算：死亡证据才算击败；撤离成功 → failed 且 problem 写明拒战线与出路；互锁处境（低血 + 无食物）写全出路（049）；拾荒失败不影响击败判定。
4. follow：迟滞起步与停止；编号重用判目标丢失；路线失败 UNREACHABLE 附开路说明；改地形受许可约束。
5. wait：先过 after_seconds 再逐刻查条件；day/night 走世界时间相位；not_hungry 阈值 18；暂停不重置计时。
6. 生存需求：饥饿三档阈值；SOON 且身上没吃的 → 创建有预算的弄吃的临时任务，弄到后走 eat 流程，弄不到 → 发事件且主任务照常；被攻击 SOON 插自卫、NOW 先撤离；贴边只在两个动作之间；夜晚有床走夜间休息、安全处不插、露天且打不过走自保。
7. 自卫临时任务：无差别选定正在威胁的实体；追击不超出打点上限；危险消失加观察期才收尾；收尾回位，回不去暂停主任务并出事件；主任务是 fight 且评估不是"打不过"时不插入，血线破了照插。
8. 换气与坠落：有水下呼吸效果不触发；顶封搜路失败即报受困；坠向深水不建自救、入水立即收尾并保留记录（068）。
9. 被埋：眼位格与头位格任一致窒即触发；只挖致窒格；受保护格拒挖并报事件；夜休与被埋同刻出现时被埋先行。

**实机验收**（追加到冒烟清单；含第 5 节全部 P 类的原事故场景）：

1. 野外一只僵尸：打得过 → 上前击杀，结果确认击败、掉落物捡起或写明没捡到。
2. 两只僵尸加一只苦力怕：苦力怕优先处理或先拉开距离再清怪；过程有事件可看。
3. 干活时被骷髅远程射中 → 自卫插入并找到射手（箭已消失），打完走回原地继续干活，事件里写明位移与红心差。
4. 主任务是打一群僵尸时新怪凑近 → 主任务继续管原目标；把它打到血线以下 → 自卫接管（对照待决定 5 的结论）。
5. 深层洞穴低血无食物被怪环绕 → 失败信息写明互锁处境与出路；先给它食物后能恢复正常交战（049）。
6. 悬崖边干活 → 只在两个动作之间退回安全处，不按秒打断；在岗贴墙施工不被抢身体。
7. 头被沙子埋住 → 立即挖围困格脱困（2026-10-05 场景 E）；同刻天黑 → 先脱困再考虑睡觉。
8. 干活时坠向深水 → 不做放水自救，入水立即恢复正常（068）；水下顶着浮冰 → 按水下路线找口，找不到报受困。
9. 夜里露天、没床、周围怪多 → 挖三填一熬到天亮；同样情形但在照明良好的矿道里 → 接着干活。
10. 饿了身上没吃的 → 临时任务弄到吃的并吃掉；箱子空的、树上没果 → 发事件后回到原任务，主任务不判失败。
11. 让它跟一位玩家保持 3 格 → 玩家走它跟、停它停；玩家退出世界 → TARGET_GONE。反射战斗用掉武器耐久 → 装备损坏有事件可查（057）。
12. 让它等到天亮 → 正常结束并写明经过时间；让它等一个永不满足的条件 → 一直等，可取消。
13. 跟随与等待的常驻任务期间天黑有床 → 夜间休息照常插入，插入与回归都有事件。
