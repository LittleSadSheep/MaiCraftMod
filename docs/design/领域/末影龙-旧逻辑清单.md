# 末影龙 旧逻辑清单（v0 dev 提交 aa97940c9）

只清点 v0 的打龙：公开能力 `defeat_ender_dragon` 一路到 `DragonFightCompanionTask` 的原生交互，以及它借用的攻击子任务里专为末影水晶写的分支。不评价、不修改。

v0 叫法说明（首次出现括注意义）：
- **子任务（child）**：打龙任务自己不动手，按阶段临时建一个移动、攻击、施工或进食任务（`MoveToTaskRecord`、`AttackTaskRecord`、`BuildTaskRecord`、`EatItemTaskRecord`），每刻推进，结束后读它的回执再决定下一步。
- **严格名单（strictAuthorized）**：攻击子任务的一种模式，只打名单上的实体；打末影水晶时用它保持爆炸距离、按回执确认摧毁。
- **决策（decision）**：失败时在结果里附 `decision.required=true`、`reason_code` 与 `recovery_options`，交给 LLM 选下一步。
- **塔区覆盖（tower coverage）**：以战斗原点为心 80 格内的区块，每一个在这一仗里都在客户端加载过一次，才承认"看不到水晶"等于"没有水晶"。

## 2 主流程

```text
MCP goal(ability=maicraft:defeat_ender_dragon, parameters)
 → AbilityAdapter.defeatEnderDragon
     allow_combat 不是 true → 决策（retry / skip / cancel），不开打
     否则拼 dragon_fight 参数（allow_combat、may_alter_terrain、minimum_health、protected_labels）
 → SemanticDragonFightTool.onGameCall：校验参数，租期 90 分钟 → DragonFightTaskRecord
 → DragonFightCompanionTask.onStart
     不在末地 / 最低血量高于最大生命 / 保护标签解析不了 / 没有活龙 / 不止一条 → 失败
     记龙的 UUID 与战斗原点（dragon.getFightOrigin()），登记出口门方块索引，初始化塔区覆盖，
     查出口门基线（开始时门在不在），扫水晶；有水晶进 CRYSTALS，否则 OBSERVE
 → onTick 每刻：
     角色死了 → CANCELLED
     observeWorld：补塔区覆盖、出口门基线、重扫水晶；观察过的水晶没回执就没了 → 失败；
                   第二条龙 / 换了一条龙 → 失败；确认阶段里同一条龙又活着 → 推翻死亡证据重来；
                   记死亡阶段、记回血
     已确认死亡状态 → CONFIRM
     正在打龙却又看到水晶或龙在回血 → 打断打龙，回水晶 / 观察
     子任务在跑：先校验目标（validateActiveWork），需要立刻恢复就打断进 RECOVER；吃饭时遇到龙息也打断
     子任务在跑 → 推进它，结束时按用途结算（finishXxx）
     需要立刻恢复（龙息、位置不安全、血低于 minimum_health、饿到 6） → RECOVER
     按阶段：
       OBSERVE   有水晶→CRYSTALS；龙在回血又看不见水晶→SURVEY（勘察超时失败）；覆盖不全→SURVEY；
                 没水晶稳定 20 刻→DRAGON
       SURVEY    朝缺的区块走一段（MoveTo）；连 4 次没新覆盖→失败
       CRYSTALS  选最近的一颗 → 安全检查（主岛范围、保护地点、爆炸范围里有旁观者、有没有弓弩）
                 → 站位不在 13~96 格的安全环里就走过去（MoveTo）→ 算不出弹道：核实是铁栏笼就开笼
                 （许可、现成站位、拆一根）否则换有视线的站位 → 攻击子任务（严格名单）→ 按回执确认摧毁
       DRAGON    有远程：龙在主岛就打；没远程：只在龙趴下、离原点 48 格内时近战；等不到窗口 4 分钟失败
                 → 攻击子任务（严格名单，12 分钟）→ 按回执与龙的状态结算，暂时性失败最多重试 4 次
       RECOVER   有龙息或位置不安全→走到避险点（MoveTo）；血低或饿→挑安全食物吃（EatItem）；
                 没得吃但饱食度够→等自然回血 800 刻；都不行→失败
       CONFIRM   龙已移除（或濒死且血归零）并且（见过死亡阶段或出口门新出现），稳定 20 刻→SUCCESS；
                 1 分钟确认不了→失败
```

公开能力 `maicraft:defeat_ender_dragon`："在末地打一条当前已加载的原版末影龙；参数放 `goal.parameters`，必须显式 `allow_combat=true`，否则开打前先返回决策。观察塔区、处理水晶与铁笼、攻击、避险与恢复，再用死亡阶段或出口门变化确认稳定的死亡或移除。龙没加载不算打赢。不负责进末地、复活龙，也不保证适配模组 Boss 机制。"目标形式 `current_place`、`area`、`prior_result`（不会自动出行到目标区域）。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `allow_combat` | boolean | 必须 `true`：允许摧毁水晶、杀龙 |
| `may_alter_terrain` | boolean | 默认 false；允许打开一个已核实的铁栏水晶笼 |
| `minimum_health` | number | 默认 10（5 颗心），1..1024 且不高于当前最大生命；低于它就脱离战斗去恢复，不保证剩多少血 |
| `protected_labels` | array<string> | 不许改动的记住地点（至多 64 个） |

内部工具 `dragon_fight` 另有 `allow_rare_consumables`（允许吃金苹果回血），公开契约没有透传。

结果字段：`phase`、`loaded_crystals_observed`、`initial_loaded_crystals`、`maximum_loaded_crystals_observed`、`crystals_confirmed_destroyed`、`crystals_still_unresolved`、`cage_openings_confirmed`、`dragon_state`（`removed_after_death_evidence` / `removed_unconfirmed` / `not_loaded_unconfirmed` / `death_phase_observed` / `dead_state_observed` / `alive_perched` / `alive_airborne`）、`dragon_health_observed`、`dragon_attack_rounds`、`dragon_healing_observations`、`healing_triggered_surveys`、`tower_coverage_required/observed/complete`、`tower_survey_moves`、`recovery_actions`、`food_consumptions_confirmed`、`rare_consumables_used`、`breath_avoidances_confirmed`、`combat_children_interrupted_for_safety`、`death_phase_observed`、`dragon_removal_observed`、`exit_portal_transition_observed`，失败时加 `decision`。面板一句话按阶段：观察战况 / 勘察地形 / 处理水晶 / 与龙战斗 / 恢复状态规避危险 / 确认龙已败北。
