# 战斗与生存需求 旧逻辑清单（v0 dev 提交 aa97940c9）

v0 叫法说明（首次出现括注意义）：
- **反射（reflex）**：客户端每刻检查的自动自救行为（防摔、换气、贴边退避、窒息脱困、自卫、夜休），注册在 `BrainChains`，按登记序号抢占当前任务。
- **身体仲裁**：`TaskSelector`/`CompanionBrain` 每刻决定"这一刻谁拿身体"的选择顺序（反射 → 同步任务 → 当前任务 → 空闲姿态）。
- **PreemptionRule / upkeep**：v1 设计文档里的词；v0 代码里没有同名类，抢占按 `TaskSelector` 的分层顺序与 `Task.stop(StopReason.PREEMPTED)` 实现，维护（upkeep）即各条反射链与随行补光。
- **任务链（chain）**：实现反射的单条行为，如 `MobDefenseChain`（自卫链）。
- **插曲（excursion）**：自卫从第一场开打到交还身体的一段记录（`DefenseExcursion`）。

## 2 主流程

**战斗（maicraft:combat → 工具 `attack` → `AttackCompanionTask`）**：
1. LLM 提交 plan，`GeneralAbilityAdapter.combat`（GeneralAbilityAdapter.java:551）校验：无 `allow_harm=true` → 决策提问；`mode=defend` 且未点名 → 直接下发 `attack`（无名单自卫）；点名则用 `findEntities`（半径默认 32，玩家包围盒外扩）挑候选；多个候选且未声明 `selection=nearest` → 决策提问；命中玩家/驯服/有名/非敌对且无 `confirm_risky_target` → 决策提问。
2. 下发 `AttackTaskRecord`，`TaskFactory` 注册到 `AttackCompanionTask`（MaiCraftCore.java:253）。
3. 任务每刻：`surveyField` 扫 `FIELD_RADIUS=14` 内敌对生物 → 组装 `Battlefield` 快照 → `AttackPlan.decide` 返回 SKIRMISH / BOW / DISENGAGE / EVADE_BLAST / DONE → 走位由 `PlayerNav` 距离带导航，武器由 `Loadout.forTarget` 挑选并经 `FirstPersonActionGate` 换手，挥击条件由 `Swing.mayStrike` 判定，弓弩由 `RangedShot` 拉弓与弹道补偿。
4. 目标死亡 → 立即转 `LootSweep` 拾荒阶段；拾荒中被追击则暂停拾取继续自卫。全部目标有死亡证据 → SUCCESS；有目标未确认击败 → FAIL。
5. 打不过 → `DISENGAGE` + `Haven`/威胁场逃跑，甩开所有追击者后以 TARGET_LOST 失败收场（回执写明拒战线与出路）。

**自动自卫（MobDefenseChain，反射 order 30）**：
1. `canRun`：`dangersNear` 非空（真实伤害记录 `CombatThreats.attackers` + 近处苦力怕主动警戒 + 锁定玩家的近身敌怪），或宽限期内；已有模型派的战斗且血量尚可则让位。
2. `begin` 建立 `DefenseExcursion`（插曲：记工位、威胁数、被打断任务）并创建无差别 `AttackCompanionTask`，拴上 `leash(工位, 16格)` 追击绳，无截止时间。
3. 危险消失后还有 `CALM_GRACE_TICKS=40` 观察期；插曲收尾时若离工位太远先以 0.8 速度步行回位，回不去则暂停被打断的任务交还模型。
4. 被 `StopReason.PREEMPTED`（更急的反射）打断时保留战斗状态，回来接着打。

**跟随（maicraft:follow → 工具 `follow` → `FollowCompanionTask`）**：
1. `GeneralAbilityAdapter.follow`（:610）先解析唯一目标（多候选且无 nearest → 决策提问），下发 `entity_id` + `distance`（默认 3，2..16）+ `may_alter_terrain`。
2. 任务常驻无截止：走出 `keepWithin+2` 才起步，回到 `keepWithin` 内停下（迟滞防抖）；空中目标导航锚取脚下地面（最多下探 64 格），停止判断仍按实体三维距离。
3. 目标消失/UUID 不符 → TARGET_LOST 失败；导航失败 → 失败并把原因与"会动哪些方块"清单交回模型。

**等待（maicraft:wait_for_condition → `IntentAction.Wait` → `IntentTask.tickWait`）**：
1. `WaitAbilityAdapter` 校验 `condition`（elapsed/day/night/health_full/not_hungry）与 `after_s`（整数 0..3600，默认 1），越界、小数、字符串一律拒绝。
2. `tickWait`（IntentTask.java:1216）：先等到 `gameTime >= 开始刻 + after_s×20`，再逐刻检查条件；条件不成立就继续等，**没有超时**，调用方只能取消。

**进食（maicraft:consume → 工具 `eat` → `EatCompanionTask`）**：
1. 前置检查：当前模式有饥饿机制（创造模式直接拒绝）、背包有该物品、物品默认带 FOOD 组件。
2. 把食物选到主手，按住使用，让原版处理动画与消耗；回食用时长 + 40 刻的截止。
3. 成功判据：同物品总量减少；数量没少 → 失败并保留"未观察到消耗"与当前饥饿值。

**身体维护（反射层，每刻先于普通任务）**：
- `TaskSelector.select`（TaskSelector.java:29）：寻死任务抑制反射 → 按注册序问各反射（换气 5 → 防摔 10 → 贴边 20 → 自卫 30 → 夜休 40 → 护甲穿回 45）→ 同步任务 → 当前任务 → 空闲姿态。释放窗口反射（贴边退避）只在身体未持有时参与；窒息脱困豁免；连续驾驶任务可让非致命反射让位（换气链声明让位）。
- 各链触发：`SurvivalDecisions`（头部在水且空气 ≤ 预计上浮用量 → 换气；未落地且下落速度 ≤ -0.7 且有方案 → 防摔；身边有威胁 → 自卫）；`SettleChain` 另判眼位/头位格窒息与贴边（4 格深落差 + 0.35 格贴边距）；`NightRestChain.canRun` 判夜间 + 32 格内有可用床 + 当前步骤是施工/取物/合成/烹饪白名单。

## 4 向 LLM 提问的出口（逐个列出问题和选项）

全部出口都在能力适配层（`GeneralAbilityAdapter`），反射链从不提问，只发 `agent.reflex` 事件：

1. **combat 未授权伤害**（GeneralAbilityAdapter.java:556）："Combat can harm or kill entities. Confirm that harm is intended before the body acts." 选项：retry（allow_harm=true）/ skip / cancel。
2. **combat 没有可打目标**（:573）："Who or what should be fought?" 选项：retry（给 entity_type_id / entity_name / player_name）/ cancel。
3. **combat 目标歧义**（:592，经 `ambiguousEntities`）："Several loaded entities match the combat target." 附候选事实，选项：retry（指定 nearest 或缩小选择器）/ cancel。
4. **combat 高风险目标**（:597）："The resolved target includes a player, tame/named entity, or non-hostile creature. This may be somebody's companion or farm animal." 附 `protected_or_non_hostile_candidates`，选项：retry（confirm_risky_target=true）/ replace_goal / cancel。
5. **combat 选择器非法**（经 `invalidSelector`）：未注册实体类型名等，选项 retry / cancel。
6. **combat 命中的加载实体为空**（经 `missingEntity`）：报告半径内无匹配，不探索。
7. **follow 没有跟随对象**（:619）："Who should be followed?" 选项：retry / cancel。
8. **follow 目标歧义**（:628）："Several loaded entities match the follow target." 选项：retry / cancel。
9. **follow 选择器非法 / 候选为空**：同 5、6。
10. **wait 参数非法**：不走决策，直接抛 `IllegalArgumentException`（condition / after_s 各一句），在计划阶段以失败返回。

## 7 跨领域依赖（引用了哪些其他领域的类，各用来做什么）

- **寻路（pathing）**：`PlayerNav`、`NavGoal`（距离带/避让/近地面目标）、`EmbeddedBaritoneRuntime`（是否在管理游泳换气、 ownsActiveLandingAssist、物理障碍快照）、`GoalAvoidEntities.Threat`（威胁场进寻路估价）、`EmergencyLanding`/`LandingAssistSession`/`LandingAssistPolicy`（落地自救方案与回执）、`SwimAirBudget`/`BreathingRoute`（换气空气预算与水下路线）。
- **导航安全（NavigationSafetyContext）**：`protectsUse`、`forbiddenBodyCells`、`canStandAt`（保护格与可站判定，夜休挑床、贴边退避共用）。
- **建筑（build）**：`BuildEdgeMotion`（站位微调/低顶挪位复用）、`BuildTaskRecord.Target`（补光确认目标）。
- **睡觉领域**：`NightRestTask`、`NightRestRouteProbe`（入睡与往返路线，夜休链调用）、`WorldTimeSemantics`（白天/夜晚/日索引，wait 条件与夜休共用）、`BedBlock.canSetSpawn`。
- **地标保护（LandmarkProtection）**：夜休继承当前步骤的保护标签。
- **实体观察（scan）**：`TargetIndex`（注册/查询床）。
- **实体属性（SheepTraits，task/entity）**：羊颜色/幼崽/剪毛过滤，跟随与战斗共用同一选择器。
- **物品（inventory）**：`PlayerInv`、`InventoryKeepPlan`、`FoodMaterialBudget`、`OrdinaryFood`（口粮统计方式）。
- **感知/交互层（client/actor、core/act）**：`FirstPersonActionGate`（换手）、`Interaction`（持续使用/攻击）、`NativeActionReceipt`/`NativeConfirmation`（原生动作回执）、`InputDriver`/`BodyControlPort`（底层输入）。
- **事件与提醒（client/runtime）**：`GameplayAttentionMonitor`（reflexStarted/Finished/Escalated 事件）、`ReminderBoard`（口粮、着火提醒挂板）、`DamageAttention`/`DamageEpisode`（伤害注意事件）。
- **任务框架（task）**：`Task`/`TaskState`/`TaskRecord`/`TaskFactory`/`CompanionTickDispatcher`/`TaskSlot`。
- **寻死（suicide）**：`SuicideArmorRestore` 注册为反射（order 45），寻死任务通过 `suppressesSurvivalReflexes` 压制全部反射。
