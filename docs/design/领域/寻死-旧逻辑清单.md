## 2 主流程

```text
goal.ability = maicraft:suicide
  → SuicideAbilityAdapter.adapt → SuicideRequest.parse（参数校验）→ SuicideTaskRecord
  → IntentTask 把它当当前步骤；suppressesSurvivalReflexes 从首刻起为真
      → TaskSelector.select 先选它，跳过全部反射（换气、防摔、贴边、自卫、夜休、护甲穿回）
      → CompanionBrain.allowsAuxiliaryWork 为假，随行补光不借身体
  → SuicideTask.tick → advance：
      1 已结束 / 换了身体 / 先看有没有已观察到的死亡 / 累计执行刻超总时长
      2 模式：创造、旁观、极限 → 失败
      3 checkRule：单人在服务端线程异步读 keepInventory（每 20 执行刻刷新，首次没回来就等）；
        多人只认调用方的 keep_inventory_confirmed；为假 → 失败
      4 GuiPreparation.ready：等菜单事务、原生关页返料、睡着就等自然醒
      5 undressed：头→胸→腿→脚逐件 UnequipCompanionTask 快速移回主背包；
        然后副手的不死图腾移回背包、主手的图腾切到空快捷栏格（没空格移回背包）；收不走的记下继续
      6 SuicideHazards：首次勘查固定起点；scan 每刻最多 1024 个脚位；choose 选最近的未放弃候选：
        地形（岩浆 / 高处 / 仙人掌）+ 每次重读的敌对生物 → 都没有时随身点火 → 最后倒岩浆桶
      7 接近：PlayerNav.walkingOnly 走到站位（地形 0.6 格内并落地，怪 5 格内并落地）；开始接近即 armed
      8 接触：岩浆停在里面；高处踏出边缘、开始下落后松水平键；仙人掌一直贴身推；
        怪 1.5 格内停住（撞墙就跳），不打、不举盾；
        自造：SuicideSelfHazard 站在格里低头对脚下顶面右键，等服务端确认与真实危险格，站着受伤，灭了再造
      9 400 执行刻没再掉血 / 导航失败 / 目标没了 / 坠落落地还活着 → 放弃这处，另选
  → 死亡：GameplayAttentionMonitor.deathDetected
      先读 auto_respawn（寻死步骤默认真）→ CompanionTickDispatcher.observeExpectedDeath → TaskSlot.observeDeath
      → IntentTask.observeDeath → SuicideTask.observeDeath（同一身体、armed、未结束 → SUCCESS）
      → 保存检查点、记死亡时库存、发 agent.died → requestNativeRespawn（player.respawn()）
      → 或开死亡恢复决定（auto_respawn=false、请求失败）
  → 结束（死亡、失败、超时、取消）：SuicideTask.handOver → SuicideArmorRestore.remember（暂停不登记）
  → SuicideArmorRestore（反射 45）：身体活着、交接结清、动作空闲、没开界面、当前步骤不是寻死时接管，
      按组件相同的原件逐件 EquipCompanionTask 穿回原部位，发 agent.reflex 开始 / 结束
```

## 8 当前对外能力说明（参数表摘要）

`goal.ability = maicraft:suicide`；`target` 省略或 null；`parameters`：

| 字段 | 类型、默认、范围 |
| --- | --- |
| `keep_inventory_confirmed` | 布尔，默认 false；多人必须给 true；单人以服务端真实规则为准 |
| `method` | auto（默认）/ lava / hostile / fall / lava_bucket / fire / cactus；指定后不回退 |
| `search_radius` | 整数 4..64，默认 24 |
| `timeout_seconds` | 整数 10..600，默认 120 |

另有两个通用键放在寻死步骤的 `parameters` 或 `preferences`：`auto_respawn`（寻死默认真）、`recover_after_death`（只记请求）。

回执 `confirmed_effect.data` 字段：`task`、`method`、`phase`（observing / approaching / exposing_to_hazard / stowing_protection / finished）、`keep_inventory_confirmed`、`rule_evidence`（unconfirmed / caller_confirmation / integrated_server）、`survival_reflexes_suppressed`、`death_observed`、`respawn_observed`（固定 false）、`health_lost`、`ignitions_confirmed`、`lava_pours_confirmed`、`armor_removed`、`armor_still_worn`、`totems_stowed`、`totems_still_held`、`execution_ticks`、`attempts`、`mechanical_retry_allowed`（固定 false）。面板行动行按方式与阶段说一句话（`SuicideTask.java:322-336`）。
