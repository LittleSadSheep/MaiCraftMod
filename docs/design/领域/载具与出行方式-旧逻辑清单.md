# 载具与出行方式 旧逻辑清单（v0 dev 提交 aa97940c9）

术语说明：v0 把一次乘电梯、一次喷气背包飞行、一次离艇叫「交通段」（`TransportSession`），把登记飞机操纵映射的档案叫「飞控档案」（`AircraftProfile`），把物理结构（Sable 子世界里的一块会动的方块）叫「物理结构」或「船体」；结构自己的坐标原点叫 `origin_storage`。下文直接用这些原叫法。

## 1 范围

能力与入口：

- `maicraft:travel` 的交通部分：`transport_mode`（auto / ground / jetpack / elevator / aircraft）、`elevator_id`、`elevator_floor`、`structure_id` 与 `seat_position`（登船）、`aircraft_id` 与 `cruise_altitude`（坐自己的飞机旅行）；内部工具 `elevator_floor`、`board_structure`。
- `maicraft:physical_balance`（受力分析、试算、配重推荐、配重施工）、`maicraft:physical_assembly`（粘接、组装、拆回）、`maicraft:physical_control`（部件设置、无线打字机配键与按键）、`maicraft:fly_vehicle`（登记操纵映射、飞行）。
- `maicraft:operate_machine` 的 `drive_vehicle`（地面载具驾驶）与 `inspect_machine` 里的控制回路读取（规则级已在[机器与任务-旧逻辑清单](机器与任务-旧逻辑清单.md) M13、M142 登记，这里展开）。
- 服务端操作 `physics.snapshot`、`physics.assembly`、`physics.flight_state`。
- 观察：`perceive` 的 `surroundings.elevators`、`focus=maicraft:physical_structure`。

已在别的清单登记、这里只引用的：`transport_mode` 的参数校验（出行清单 T-06、T-07、T-12）、按方向找平台的喷气背包兜底（T-49）、出发时在船上先航行（T-40，原版船，里程碑四）。

v0 没有的：Create 火车（第 3.11 节只记用户的要求）。放置细节（漏斗挂带、隧道、机械臂选点、强力胶选区、铺轨两点）由里程碑三的机器会话按机器规格的安装段做，不在本清单。

## 2 主流程

**交通段怎么插进一次移动**（`TransportNavigator.tick`）：

1. 有旧交通段在跑就先等它结束，不同时开第二种移动方式（`TransportNavigator.java:105-107`）。
2. 交通段结束：不确定或已出手后失败 → 整次移动以 UNKNOWN 失败，话术"交通改动了身体或装备，先检查再重试"（114-121 行）；成功但身体挪动不到 0.25 格 → 失败（125-128 行）；成功 → 交回地面导航续走，"一段结束不代表到达"（129-131 行）。
3. 喷气背包还没起飞就被头顶挡住（`jetpack_departure_blocked`）→ 同一任务内先走到附近净空处，再重新规划飞行（137-147 行）。
4. 指定了 jetpack / elevator → 先用它；auto → 先走路，走路以 NO_PATH / TERRAIN_BLOCKED / BOXED_IN / NO_MATERIAL 失败才找交通（229-238 行）。
5. 找交通：`TransportTargets` 分刻搜满足目的地的落点 → `TransportPlan.prepare` 按方式生成报价（auto 先给"离艇"，再给各平台的喷气背包，再给各楼层的电梯；远端没加载时按目的地给电梯楼层线索）→ 按预计耗时排序，一次试一个，试过的按（方式, 起点, 终点）记住。

**电梯**（`CreateElevatorTravel`，阶段 DISCOVER → APPROACH_CALL → CALL → WAIT → APPROACH_BOARD → BOARD → WALK_CONTROL → SELECT → RIDE → WALK_EXIT → EXIT）：找已加载的轿厢，没同步楼层表就先请求；选能连通出发层与目标层的路线；走到呼梯按钮或无线链路旁按下（或用手持遥控器）；等轿厢到达本层停稳；走进轿厢里有支撑的内部格；走到装置控制器前选层；站着不动等到层；走出到目标层的固定平台，站稳 3 刻算完。

**喷气背包**（`JetpackFlightSession`，PLAN → ACTIVE → HOVER → FLY → REPLAN → LAND → RESTORE → DONE）：读胸甲槽的背包与气罐 → 规划 64 格内的六向路线 → 开飞行、开悬停 → 疾跑巡航沿路线飞 → 到落点上方关包下降、近地重开制动 → 原生接地 → 恢复出发前的开关状态。

**登船与离艇**：`board_structure` 只支持喷气背包飞上甲板（`ShipLandingTarget` 选甲板内部落点，原生接触且稳定 8 刻算登上）；`seat_position` 再走到座位侧面空手右键入座（`StructureSeatTask`）。离艇是 auto 模式的第一个报价：从静止甲板走到船沿，落差三格内、低顶处潜行（`StructureDeparture`、`StructureExitPath`）。

**物理结构四个能力**：`physical_assembly`（inspect / bond 备胶走到两端点提交一次选区 / assemble 与 disassemble 拉一次组装器等真实转换）、`physical_balance`（analyze / simulate / recommend 只读，apply 真实挖放配重后重算）、`physical_control`（inspect / 各种 set_* / 螺旋桨装拆 / 摇曲柄 / 换轮胎 / 打字机配键与按住）、`fly_vehicle`（inspect / configure 存飞控档案 / fly 入座、接管打字机、飞到落点、松键停稳）。`travel` 的 `transport_mode=aircraft` 把 fly_vehicle 包成"登机 → 飞 → 降落 → 下机 → 末段步行"。

**地面载具**（`VehicleDriveTask`）：找驾驶座与座上够得着的控制件 → 入座 → 读控制回路推出中性输入 → 逐档试探学到"哪个输入让车怎么动" → 朝目的地开 → 到达后回中性、松开。

## 7 跨领域依赖

- **寻路**：Baritone 分叉的 `CollisionGeometry` 取移动结构碰撞的供应者（v1 已移植接口，供应的是空快照）；`LoadedTravelLeg` 远端分段 v1 已移植。
- **生存需求**：坐在载具上掉落时坠落自救把驾驶控制交回（VB-13）；落地救援（v1 第十八轮的 `behavior.landing`）没有喷气背包这一招，所有者待定。
- **战斗**：交通中受伤（VT-16、VJ-20）。
- **机器**：控制回路读取挂在 `inspect_machine`（机器清单 M142）；在船上施工（`StructureEditTask`）和机器施工共用原生安装物规则。
- **感知**：`surroundings.elevators`、`focus=maicraft:physical_structure`（`PhysicalStructurePerception`）。
- **记忆**：飞行沿途的群系与结构记录（VF-16）；飞控档案存 SQLite（VF-01）。
- **服务端**：`physics.snapshot`、`physics.assembly`、`physics.flight_state` 三个只读操作。

## 8 对外能力说明

- **travel 交通字段**：`transport_mode` auto|ground|jetpack|elevator|aircraft（默认 auto，指定方式不放宽动土）；`elevator_id`、`elevator_floor`（ask / top / bottom / next_up / next_down / 楼层名）；`structure_id`（用喷气背包登船，不与其他目的地同给）、`seat_position`；`aircraft_id`、`cruise_altitude`（只配 aircraft）。
- **physical_balance**：`structure_id` 必填；`operation` analyze|simulate|recommend|apply；`reference_rpm`、`controls`、`wheel_brakes`、`reference_velocity`、`balloon_fill` 只改试算；`edits` / `ballast_candidates` 用 `origin_storage` 偏移。
- **physical_assembly**：`operation` inspect|bond|assemble|disassemble；`structure_id` 与世界 target 二选一；胶的种类（强力胶 / 蜂蜜胶）与两个端点。
- **physical_control**：`operation` inspect、set_speed、set_throttle、set_burner_volume、set_spring_angle、set_link_mode、set_frequency、assemble_propeller / disassemble_propeller、turn_crank、set_tire、bind_typewriter_key、press_typewriter_keys；`require_onboard`、`observe_positions`、保持刻数。
- **fly_vehicle**：`structure_id` 必填；`operation` inspect|configure|fly；`profile`（完整对象）；fly 恰好给 target 或 `direction`（八个方向）之一，`distance` 16..8192，`cruise_altitude`。
- **operate_machine.drive_vehicle**：`structure_id` + 目的地 target。

说明文字共约 1.6 万字符，大量篇幅在讲"成功不等于能飞""发送不等于收键"这类回执口径。
