## 原版船

现在：隔着湖、海的目的地，`travel` 只会泅渡或绕路。坐原版船只有跟随里的同乘（`ability.follow.VanillaRideAlong`：跟着的人坐了船，另一个座空着就走过去坐上）；落地救援会在坠落时放一条船接住自己（`behavior.landing.BoatRescue`）。自己划船去对岸没有。

真人怎么做：要过湖就掏出船放到水边、坐上去、对着对岸划、靠岸跳下来接着走；岸边停着一条没人坐的船就直接用它。身上没船、岸边也没船，就游过去或绕路，不会为过一次湖现做一条船。

要做成：登记成一种出行方式（`behavior.travel.spi.TravelMode`，和电梯、末地折跃门一样由行程规划比报价），取值 `boat`。

- 报价（只读）：人和目的地之间隔着一片连起来的水、走路算不出干路或绕得很远，且身上有船物品、或 32 格内停着一条没人坐的船，就出一份。耗时按船在水上约每秒 8 格估，加上放船、上船、下船各几秒。没船、下界、水面冻住，不出报价并说一句原因。人正坐在原版船上时这一段非它不可：先开到最近的岸再下船，不交给走路。
- 一段怎么走：备船（身上有船先换到主手；岸边停着的船直接走过去用）→ 走到岸边能放船的站位（脚下站得住，前面一格是水面）→ 对着水面右键放船，确认附近出现一条新的船（落地救援放船时用的是同一种确认：在放的位置附近找船实体）→ 右键船坐上去，确认坐的正是它（同乘的上船动作可以复用）→ 按住前进、左右转向，朝目的地那边岸上的落点划。每刻看前方：撞岸、搁浅、顶到睡莲或冰就倒退一下再转向，连着三次没前进换一个靠岸点。路上饿了、被打照常让生存需求打断，船停在原地，回来接着划 → 贴岸后潜行下船，确认人已经不在船上、脚下站得住 → 船留在岸边不收，位置记进世界记忆，下次从这边回去先用它 → 交还行程，从岸上接着走。
- 结果：`legs` 里这一段写 `via=boat`；`changes` 记放下了一条船（身上少了一条）和船留在哪；没划到就写清停在哪、为什么（撞岸三次、船被打碎、人被拉下船）。
- 不做：身上没船不现合成；不在船上打架；不替别人划（同乘归跟随）。
- 离线测试：报价、"非它不可"的判断、靠岸点挑选、划船的转向都做成纯函数，用替身测。
- 实机验收：站在湖边、身上有船、目的地在对岸，放船划过去下船走到；岸边停着一条船、身上没有，走过去坐那条；划到一半被僵尸打，停船应付完回来接着划；身上没船也没停着的船，不出报价，行程照常泅渡或绕路，结果写明。

## 原版矿车

现在：Create 火车按时刻表能坐（模组那一半，不归这里），原版铁轨上的矿车没有任何支持，铺好的轨道角色只会沿着走。

真人怎么做：轨道起点放一辆矿车坐上去，有通电的动力铁轨就自己走，没有就靠下坡；到地方按潜行下车。原版矿车里的人推不动车，所以没动力又不下坡的线路不坐。

要做成：登记成出行方式，取值 `minecart`。

- 报价：读已加载区里连成一条的铁轨（普通、动力、探测、激活四种），离人最近的轨道格和离目的地最近的轨道格之间连得通、沿途有通电的动力铁轨或一路下坡能把车送到头，且身上有矿车、或轨道上停着一辆没人坐的矿车，就出报价，按约每秒 8 格估。线路这一刻没读完就先不答，下一刻再看；没车、不连通、没动力，不出报价并说一句原因。人正坐在矿车里时这一段非它不可：先坐到头或下车。
- 一段怎么走：备车 → 走到起点轨道旁 → 对着轨道右键放车，确认附近出现一辆新的矿车 → 坐上去 → 起点是通电的动力铁轨就自己走；不是就先从后面推一下再跳上去，或者把车放在下坡的起点 → 坐着每刻看车动没动、到了哪；停在半路（动力铁轨没电、撞上停着的车、轨道断了）就下车，记下停在哪 → 到离目的地最近的轨道格潜行下车 → 车留在原地，位置记进世界记忆 → 交还行程。
- 结果：同原版船。
- 不做：不铺轨、不放动力铁轨、不给红石通电（那是建造和 `use` 的事）；身上没车不现合成。
- 离线测试：铁轨连通与能不能送到头做成纯函数（四种铁轨、拐弯、坡道、丁字路口按原版规则）。
- 实机验收：一条带通电动力铁轨的直线，放车坐到头下车；线路中间没电，停在那里下车，结果写明停在哪；身上没车、轨道上停着一辆，坐那辆。

## 施工不跑酷

现在：走路的引擎设置里跑酷一直开着（`behavior.navigation.baritone.BaritoneInternals` 里 `allowParkour` 恒为真）。施工时角色在脚手架、刚砌的墙头上换站位，几格的距离也会跑酷跳，容易从高处跳下去、跳过缺口掉下去，看着也一顿一顿的。

真人怎么做：在脚手架上干活时一步一步挪，不跳；赶长路时才跑跳。

要做成：施工发起的走路（`behavior.construction.LiveTravels` 交给走到的那几段）不跑酷、不跑跳；其余走路照旧。做法上可以在交给走到的地形许可里多带一个"不跑酷"的开关，由 `TerrainSwitches` 落到引擎设置；别改成"按距离猜是不是施工"。

- 离线测试：施工发起的走路引擎设置里跑酷是关的，普通出行是开的。
- 实机验收：盖一座三层高的塔，脚手架上换站位一步一步走、不跳；盖完沿土柱下来，路上不跑酷跳下。

## 挖脚下那格

现在：要采集、挖掘的方块正好在脚下时，站位判断没有专门看那一格下面是什么，挖穿了人就掉下去。往下跳的高度已经按"摔完还剩一半血"放宽，掉进深坑多半还活着；掉进岩浆就是死。

真人怎么做：要挖脚下那一格，先看一眼下面：下面是岩浆、或者是看不见底的洞，就挪到旁边一格站着挖它；下面是实地、或掉下去摔不坏，就直接挖。

要做成：先核：读 `ability.gather.GatherTask` 和站位模型（`behavior.approach.StandSpots`、`LiveApproachWorld`），确认要挖的方块正好是脚下那格时现在怎么选站位、挖穿后掉不掉。确实会掉就改：这种情况下站位换到旁边够得着、看得见它的一格（不是拒绝，是换个站的地方）；旁边一格都站不了，照挖并在结果里写一句下面是什么。往下挖楼梯（`behavior.acquire.ClientStairsDown`）有自己的一套，不在这一项里。

- 离线测试：脚下那格下面是岩浆时站位换到旁边；下面是实地时原地挖。
- 实机验收：站在岩浆池上方一格的石头上让它采脚下这块石头，它挪到旁边去挖，人不掉进岩浆。
