## v0 的维护规则

- **冻结功能**：不加新能力、新参数、新行为。
- **只修影响直播的问题**，并且修法以最小改动为准。修复时顺手在对应领域旧逻辑清单里记一笔（"v0 在这里出过这个问题"），供 v1 规格参考。
- v0 的提交规则不变（`dev` 分支、签名、中文 Conventional Commits、更新日志）。
- `dev` 上的 `docs/refactor/` 改为一份指向说明，设计文档以 `v1` 分支的 `docs/design/` 为准。

## 切换标准（每个里程碑都一样）

某类直播从 v0 切到 v1，需要同时满足：

1. 该里程碑包含的所有领域规格都已实现，离线测试全部通过；
2. 下文"实机验收清单"中，该里程碑的条目全部通过；
3. 一次完整的试播（不少于 1 小时，按真实直播流程，由 Amaidesu 的 v1 Agent 驱动）没有阻塞问题；
4. Amaidesu 的 v1 Minecraft Agent 提示词与 skills 已按新能力更新；
5. 两位确认。

切换后，该类直播出问题只在 v1 修。

## 实机验收清单

每个里程碑结束、每次切换前，由人在实机跑一遍。领域规格第 9 节的实机项会追加到这里。

**里程碑一**

1. 新世界开局：砍树 → 工作台 → 木镐 → 挖石头 → 石镐 → 熔炉 → 烤肉 → 吃。
2. `observe(scene)` 的描述与画面一致；用观察编号让它去砍"左前方那片树林"里的树。
3. 天黑：世界里有床、背包里有床、只有羊毛和木板、什么都没有，四种情况。
4. 打开附近箱子取指定物品；背包塞满后继续取物，看它怎么腾地方。
5. 记住一个地点，走远后让它回去。
6. 野外遇到僵尸和苦力怕：打得过就打，打不过就跑；夜里露天没床又打不过时挖三填一。
7. 干活时掉进深水、被沙子埋住，先自救再继续。

**里程碑二（建造）**，来自建造规格第 9 节：

1. LLM 用 `design(create)` 画一间 7×5 的木屋（墙、门、两扇窗、屋顶），`inspect` 看一眼，`preview` 投到空地上观众能看见半透明屋子；`build` 在同一处盖起来，门最后关好，结果每格 MATCHES。
2. 同一张图纸换个地方转 90 度再盖一次；盖到一半 `goal(cancel)`，垫的土被收走，世界里只剩已砌好的部分；再下达一次接着盖完。
3. 身上只有一半的石砖：盖到石砖用完停下，结果 partial 写明还缺多少；`obtain` 补齐再 `build`，从停下的地方接着砌。
4. 工地上有一棵树和一个坑：树被砍、坑被填，余土进旁边的箱子或被丢掉。
5. 工地边缘压着玩家的箱子：提问 NEED_APPROVAL 列出那几格；回答不同意 → 跳过那几格盖完其余。
6. 图纸里有一个水池：实心格放完后倒水；再盖一个岩浆池，倒下去成黑曜石时结果如实记。
7. 高塔：够不着的格先垫土柱，放完沿柱下撤，塔底没有残留的土。
8. 导入一个 .litematic 的小房子，箱子是空的、展示框没装，结果写明没装几个。
9. 施工中天黑：夜休在两格之间插进来，睡醒回到工地接着砌。
10. 只放一个火把：`build` 给 `block=minecraft:torch` 和 `target=seen b#`（墙面），火把贴在墙上。

**原版各领域**，来自各领域规格的实机验收：

交互与容器：

1. 洪水区里让它用空桶舀水 → 舀到水源，不对着流动的水空点。
2. 站位和目标有高低差时播种、舀水 → 换到合适的站位后成功，不出现"提交了没反应"的空转。
3. 河岸上锄地，第一个站位不生效 → 自己换站位锄成。
4. 往告示牌上写两行字，事先留一个没关的编辑界面 → 照样写成，结果里是实际写下的字。
5. 箱子上方压着一块不受保护的实心方块 → 先敲掉再存；上方是别人放的方块 → 提问；上方是树叶 → 照常打开（树叶压不住箱盖）。
6. 用打火石点下界传送门框 → 出现火或门成形都算点着，火熄灭不算失败。
7. 让它点燃自己脚下那一格 → 换一个不会点着自己的站位再点。
8. 主播站在箱子旁边时让它存东西 → 照常存。
9. 存一大包杂物，附近两只箱子，第一只装满 → 自动换第二只；都满了，报告剩多少。
10. 存东西不给 items → 工具、武器、护甲、食物、火把和一组方块留在身上。
11. 用观察编号指定一只白羊让它剪毛 → 羊毛进背包。
12. 让它坐上船、骑上马；已经在上面时直接完成。
13. 对村民用 `use` → 打开交易界面，列出内容，关上。
14. 在下界对床用 `use` → 不点，结果是 DANGER。

出行与寻找：

1. 平地让它走到 50 格外的坐标 → 走到、站实，结果位置与实际一致；给全 y 与只给 x/z 各来一次。
2. 隔一条河让它去对岸 → 泅渡过河、上岸站实；中途憋气先浮上来换气再接着走，不被打断切碎。
3. 让它上一面山坡 → 走上去或垫方块上去，垫了什么在 changes 里。
4. 不给动土许可让它去一个被树挡住的地方 → 如实 UNREACHABLE，建议里写明授权动土能过；授权后同一路线能走通，全程不踩农田。
5. 让它去脚边 1.5 格的一个位置 → 直接完成"已经到了"，不报无路。
6. 让它去一个永远到不了的高度（y 提示过高）→ 先走近那一列，如实报告找不到能站的格子，不空转烧尽预算。
7. 地下让它去一个要挖洞才能到的目标 → 授权后能挖到或以 STUCK 如实结束，不无限烧预算。
8. 走到一半取消 → 人停在实际位置，结果 partial 写明停在哪、离目标多远；进度事件里剩余距离与真实位置一致。
9. 让它找附近的煤矿 → 返回观察编号与位置，编号能直接用来下达"去那里"。
10. 放一个方块后立刻让它找这种方块 → 能找到。
11. 让它找末影龙（创造模式生成）→ 一条龙一个编号，详情带血量。
12. 让它找一种附近没有的方块 → 结果写清"半径 X 格的已加载区没有"，不冒充全世界没有。
13. 报到达时人确实站在目标容差内，话术与容差同源。

回露天：

1. 在深处的矿道里让它回到头顶见天的地面（默认许可）→ 斜着挖楼梯上到地面，changes 里是楼梯挖掉的方块，人站在露天。
2. 站在山崖檐下（头顶有石头、两步外见天）→ 直接走出去，不挖。
3. 在天然洞穴里、不给动土许可 → 顺着洞走出去；洞口太远走不到时如实 UNREACHABLE，说清找了多大范围。
4. 楼梯挖到一半前面是地下水 → 换个方向接着挖，不让水灌进楼梯。

跨维度：

1. 主世界走近现成的下界门让它去下界 → 走到门口、直走进门、传送，报告的落点与 1:8 换算预期相符（偏差如实写明）。
2. 从下界同一扇门回来 → 双向往返跑通，进门后离门口结算，不被重入冷却绊住。
3. 没门的区域让它去下界（默认许可）→ 勘察、备黑曜石与打火石、搭门框、点火、验活、进门，一个目标里完成。
4. 不给动土许可时同样目标 → 按没门如实结束，建议授权动地形。
5. 出发点紧邻一扇下界门，让它去同维度附近的目标 → 路线不穿门抄近路。
6. 让它去一个模组维度 → UNSUPPORTED，如实说明目前只支持主世界、下界、末地。
7. 让它去末地 → 到要塞、插眼激活、进门落在末地平台上，结果写明单程。
8. 身上没有黑曜石，在岩浆池岸边、只有一只桶和打火石时让它去下界 → 舀水、填直弯岸、挡块放水、十桶浇出框、拆模具、点火、进门；观众看得到每一桶。
9. 同一处身上有十块黑曜石 → 直接摆框，不去碰岩浆。
10. 平原上没有岩浆、没有黑曜石 → 结果 NEED_ITEM 写清查了 128 格没池、缺黑曜石或钻石镐；用 `explore` 留意岩浆后再来能接上。
11. 池子只有一格深（底下石头）→ 底行先挖再浇，成型。
12. 浇到一半人为把水收走 → 任务补一桶水接着浇；再收走 → 如实停下，模具收回、桶里岩浆倒回池。
13. 打完龙、门亮着，让它回主世界 → 走到门边跳进去；第一次放终末之诗被关掉，落在床边，结果写了出口门送回重生点。
14. 第二次（看过制作人员名单）同样的目标 → 不放终末之诗，直接回去。
15. 龙还活着时同样的目标 → 一步不走，说要先打败末影龙。
16. 出口门亮着、带主世界坐标的目标 → 回到重生点后接着走过去。
17. 打过一次龙的主岛，让它去外岛的一个坐标 → 找折跃门、备末影珍珠、垫到门边、扔进去、落在外岛，接着走过去。
18. 在外岛让它过折跃门回主岛 → 回到主岛那扇门附近。
19. 不许用稀有品 → 照样备珍珠、扔珍珠过门。
20. 站位刻意偏一点（或门刚被用过）→ 记一次没进门，再扔一次。
21. 打过一次龙的世界，主世界去外岛的一个坐标 → 进末地门、走到折跃门边、扔珍珠、落在外岛、走过去，一趟完成。
22. 同样的目标不给用稀有品的许可 → 照样一趟走完。
23. 在外岛让它回主世界 → 扔珍珠回主岛、走出口门、落在重生点。
24. 外岛上回主世界、龙又被复活了 → 回到主岛后说要先打败末影龙。

吃穿与背包：

1. 让它吃一个面包 → 拿到手上吃完，饱食度上升，结果写明消耗与效果（无）。
2. 饱食度满时让它吃面包 → 立即结束："饱了，吃不下"；让它吃金苹果 → 吃得下，效果写进结果。
3. 身上只有腐肉，让它随便吃点 → 吃腐肉；身上只有金苹果或河豚 → 以 NEED_ITEM 结束并写清有哪些，点名后才吃。
4. 头上戴着铁头盔再让它戴铁头盔 → 直接完成"已经戴着"；卸下头盔 → 背包里多一个头盔。
5. 背包只剩一格且装着钻石镐，让它卸下胸甲 → 腾地方不丢钻石镐（合并堆叠或进附近箱子），卸下成功。
6. 让它丢 5 个圆石、丢身上没有的东西、丢 100 个但只有 30 个 → 分别得到 done、NEED_ITEM、partial，数字对得上。
7. 在开阔平地让它丢一组泥土 → 朝远处整份抛出，角色走开，物品没被自己吸回；随后让它走过那片区域 → 路线绕开落点。
8. 断网或高延迟时让它丢东西，确认没等到 → 结果是 unconfirmed 而不是"确定没丢"或"确定丢了"。
9. 露天平地上让它丢一组石头 → 正常丢出，不出现"无可丢弃区"。

战斗与陪伴：

1. 野外一只僵尸：打得过 → 上前击杀，结果确认击败、掉落物捡起或写明没捡到。
2. 两只僵尸加一只苦力怕：苦力怕优先处理或先拉开距离再清怪；过程有事件可看。
3. 干活时被骷髅远程射中 → 自卫插入并找到射手（箭已消失），打完走回原地继续干活，事件里写明位移与红心差。
4. 主任务是打一群僵尸时新怪凑近 → 主任务继续管原目标；把它打到血线以下 → 自卫接管。
5. 深层洞穴低血无食物被怪环绕 → 失败信息写明互锁处境与出路；先给它食物后能恢复正常交战。
6. 悬崖边干活 → 只在两个动作之间退回安全处，不按秒打断；在岗贴墙施工不被抢身体。
7. 头被沙子埋住 → 立即挖围困格脱困；同刻天黑 → 先脱困再考虑睡觉。
8. 干活时坠向深水 → 不做放水自救，入水立即恢复正常；水下顶着浮冰 → 按水下路线找口，找不到报受困。
9. 夜里露天、没床、周围怪多 → 挖三填一熬到天亮；同样情形但在照明良好的矿道里 → 接着干活。
10. 饿了身上没吃的 → 临时任务弄到吃的并吃掉；箱子空的、树上没果 → 发事件后回到原任务，主任务不判失败。
11. 让它跟一位玩家保持 3 格 → 玩家走它跟、停它停；玩家退出世界 → TARGET_GONE。反射战斗用掉武器耐久 → 装备损坏有事件可查。
12. 让它等到天亮 → 正常结束并写明经过时间；让它等一个永不满足的条件 → 一直等，可取消。
13. 等待的常驻任务期间天黑有床 → 夜间休息照常插入，插入与回归都有事件；跟随期间他不睡 → 不插，他躺下了 → 在附近找床睡，睡醒接着跟。
14. 跟一位疾跑的玩家穿过一片平地 → 一路跟着跑，不走一段停一段；他停下 → 进 3 格停住、不撞上去，转头看着他。
15. 他朝角色径直走过来、或在一格宽的走廊里迎面走来 → 角色让到一边。
16. 他搭柱子上了 6 格高台、不给动土许可 → 角色停在台下看着他，事件说过不去；他下来 → 接着跟。
17. 他走进下界门 → 角色跟进去，在下界找到他接着跟；他退出游戏 → 事件说下线了，30 秒后 TARGET_GONE。
18. 他放一条船坐进去 → 角色坐上同一条船；他划到对岸下船 → 角色也下船接着跟。
19. 他被两只僵尸围着打 → 角色上去帮着打，打完回来跟；同样场景 `fight=self_defense` → 不帮。

战斗重构：

1. 夜里平地，铁剑铁甲，对 3 僵尸 + 2 骷髅：活下来、清完、回打点。
2. 木剑对大史莱姆：站在够得着又不挨打的距离砍，不贴脸。
3. 空手开局夜里被围：往没怪的方向撤、甩开；撤不掉挖三填一。
4. 骷髅站在 4 格高台上：有弓对射，没弓写明够不着。
5. 另一位玩家打角色：角色退开举盾、停下手上的事、事件里有玩家名；下达打斗后对打，对方停手后收手。

探索：

1. 平原让它自由跑图 256 格 → 走到范围边附近收工，结果写到达半径；沿途群系进世界记忆，看世界记忆的观察里看得到。
2. 让它朝一个方向找指定群系 → 出发后调转视角，搜索方向不变；走到后站实，结果带核实位置。
3. 复杂出发点（崖壁、水线）让它定向探索走不到的目标 → 换出发点、轮换后要么走出去要么如实受阻并说清历史，不原地空转。
4. 湖泊、河流地形跑图 → 不把身体领进深水长泅；短促渡水能过，滞水守卫生效换向。
5. 让它向前找一块能站的平台 → 站上的地方四邻至少 3 格同高支撑。
6. 在地下矿道让它回露天 → 授权动土时竖直上掘破出；头顶是水时不硬钻、换地方；结果写明露天证据的列高。
7. 跑图路过村庄 → 结构线索入世界记忆且来源是远望；让它走过去后升级为到访。
8. 给它留意岩浆湖 → 途中发现进结果与世界记忆，任务事件有一条发现通知；角色不因发现停在原地。
9. 目标群系在半径边界外 → 不越过硬边界追，截停如实报告只搜了半径内的已加载地形。

照明：

1. 白天一片农田，补光只管作物和耕地：它用手上的火把沿田边插灯（身上不够就先插够用的、写明缺口，不自己去做灯），复测全部达标；结果写明光源与覆盖率。
2. 夜里一间没灯的屋子（地标不带半径）→ 连通空间采样、插灯，全屋达标；"开始时已满足"的屋子再下一次 → 零动作。
3. 场地里有玩家的箱子和种着的耕地：箱子不作灯座、耕地不压不踩，照明其余；碰到受保护格提问 NEED_APPROVAL。
4. 身上只有几支火把要照大厅 → 用完如实 partial 写明还缺多少；用 `obtain` 补齐再 `light`，从暗格接着插。
5. 夜里让它走一条无灯矿道（身上有火把）→ 途中顺手插火把，不专门停路；火把用完只报告、照常走。
6. 走到一半查询补光状态 → 开着、阈值、身上与副手火把数、最近暗格如实。
7. 插火把的途中被袭击或饿了 → 随行让位（只在两个动作之间），自卫或吃饭照常，回来接着走。
8. 关掉随行补光后再走暗处 → 不再插；已插的灯留着。

物资：

1. 身上没有火把时让它拿 8 个火把 → 它砍木、做台、合成，结果写明每步来源与数量。
2. 让它只走合成再做 2 个木板 → 不去挖原木。
3. 记忆里有个箱子装着面包，让它拿 3 个面包 → 走到箱子、开箱、取出，箱子里没那么多就如实 partial。
4. 让它采一片成熟小麦 → 收进包并补种；拔掉几株再让它采 → 只收剩下的成熟株。
5. 徒手（或木镐）让它挖黑曜石 → NEED_ITEM，写清需要钻石镐，而不是"没有可行路径"。
6. 让它挖 1 个砾石堆出燧石，连续不出 → 多试几轮后才结束，不会一轮就报全部来源作废。
7. 合成中途把工作台拆掉 → 它重新盘来源（再做台或换配方），已消耗的材料如实出现在 changes。
8. 背包快满时让它合成一批东西 → 先合并、进随身包或附近箱子，不动贵重品，合成照常完成。
9. 让它靠交易买东西 → UNSUPPORTED"交易还没接入"，不空转。
10. 记得两台熔炉，近的那台投入口放着别人的生牛肉，让它烧铁锭 → 打开近的看一眼、关上、走去远的那台烧；三台都放着别人的东西 → 收场写明三台各在哪、放着什么，别人的东西一件没动。
11. 新存档里箱子的配方还没解锁，让它做一个箱子 → 在工作台上一格一格摆八块木板、取出箱子；身上的木板改过名（配方簿不认）也照样一格一格摆上做出来。

寻死：

1. 单人、开着死亡不掉落、旁边有岩浆湖，不给死法 → 脱甲收图腾 → 走进岩浆 → 自动重生 → 床边穿回护甲，结果完成。
2. 洞里没有现成危险、身上有打火石 → 原地点火烧死。
3. 沙漠平地只有仙人掌 → 贴着仙人掌死。
4. 旁边有 6 格小坎和 30 格悬崖 → 只跳悬崖。
5. 夜里有僵尸、点名敌对生物死法 → 走过去站着挨打，不还手、不举盾。
6. 背包满：护甲脱不下，照样寻死，结果写明带着死的护甲。
7. 世界关着死亡不掉落时不做；连别的服务器、没确认死亡不掉落 → 先提问确认，按回答办。
8. 点火瞄不准 → 换下一种死法或如实结束，不无限循环。
9. 寻死途中取消 → 先穿回护甲再结束。

末影龙：

1. 新世界生存模式，铁剑、弓、64 支箭、铁甲、牛排，传送进末地：射掉八颗没笼子的水晶，笼子两颗如实写进结果；打死龙；收到经验；结果里有死亡阶段、消失、门亮三样证据。
2. 同上不带弓 → 开打前 NEED_ITEM 弓和箭。
3. 龙趴着：扫视、吼的时候砍头，吼完前退出龙头前方，喷的十秒不站进云里，也不贴着龙头龙脖子挨撞。
4. 龙冲撞：角色横着跑开或举盾，不被扇下岛。
5. 血打到 6 颗心：退开吃东西，回到 9 颗心再回来。
6. 末影人很多的地方：全程没有因为对视惹毛末影人（日志里没有被末影人追的记录）；故意打一只，它惹毛后被近身打死，接着打龙。
7. 没在打龙时被龙撞：自卫不追龙。

原版船：

1. 站在湖边、身上有船、目的地在对岸 → 放船划过去、下船走到接着走，`changes` 里记放下的船和船留在哪。
2. 岸边停着一条没人坐的船、身上没带船 → 直接走过去用那一条，身上的东西一件不少。
3. 划到一半被僵尸打 → 停船应付（船停在原地），应付完回来接着划。
4. 身上没船、岸边也没有 → 不出划船这一段，行程照常泅渡或绕路，结果写明原因。

原版矿车：

1. 一条带通电动力铁轨的直线 → 放车坐上去自己走到头，潜行下车，车留在原地记进世界记忆。
2. 线路中间的动力铁轨没通电 → 停在那里下车，结果写明停在哪、为什么。
3. 身上没车、起点轨道旁停着一辆没人坐的 → 坐那辆，不消耗身上的东西。

**里程碑二其余领域与三、四**：模组领域（出行方式、机器、载具、随身背包、知识检索、任务书）在对应领域规格批准时补充。

## 并行建议

- 阶段 0 的领域旧逻辑清单可以和阶段 1、2 同时进行。
- 阶段 1 中，WP-1.4 至 WP-1.8 彼此独立，可以并行（都依赖 WP-1.1、WP-1.2）。
- WP-1.9 不依赖阶段 2，随时可以做；必须在里程碑二接随身背包来源之前完成，那是第一个真正的联动模组。
- 阶段 2 中，WP-2.4、WP-2.5 依赖 WP-2.3；WP-2.6 依赖 WP-2.4。
- 阶段 3 的各模型彼此独立，可以并行；但每个模型只做到当前领域用得到的程度。
- 阶段 4 一次只换一个领域，下一个领域的旧逻辑清单与规格可以提前做。
