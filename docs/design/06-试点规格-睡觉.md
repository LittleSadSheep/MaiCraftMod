## 2 真人怎么做

被叫去睡觉：先看现在能不能睡（在下界或末地睡会爆炸，白天睡不了）。白天不会站在原地干等到天黑——先确认今晚有床可睡（没有就趁白天弄一张），然后说一声"现在睡不了，天黑了再睡"，接着干别的。夜里就尽量睡床：找一张最近的、没人占、旁边没怪的床走过去；被墙挡着就绕到能看见床头的那一边。附近没有床，背包里有就找块平地放下；连床都没有，就用羊毛和木板现做一张，羊毛不够就去剪羊毛或打几只野羊。床边有怪：打得过、也愿意打，就清掉再睡；打不过，就把床带上，换个没怪的地方放下再睡。实在弄不到床，就直说缺什么。

只有极端情况——夜里在野外、怎么也弄不到床、怪又多又打不过——才挖三填一，把自己封在坑里熬到天亮。

夜里干活干到一半困了，也是同一套：找个空档去睡，睡醒了回到原来干活的地方接着干。去之前先确认睡醒以后回得来——能从高台上跳下去，不代表能爬回去。

## 3 新逻辑

```text
0 已满足     正在床上睡着 → 完成
1 世界规则   当前维度的床会爆炸 → 结束，blocker = WORLD_RULE（不提问）
2 时间窗口   不在原版可睡窗口（白天）→ 不干等：
               确认今晚有床（第 3、4 步，只做到"床在身上或附近有可用的床"为止，不去床边）
               → 以 outcome = partial 结束：achieved 写"今晚的床已备好"，remaining 写"入睡"，
                 blocker = TIME_WINDOW（附"约 N 分钟后可睡"）；夜间自动休息开着时，天黑后会在干活间隙自己去睡
             夜休差事去床途中夜晚被别人跳过（多人或反射睡过）→ 视为已经度过这一夜，差事结清
3 选床       BedChooser（纯函数）
             候选 = 已加载范围内的床 ∪ 记忆里的床（M9，到场复核）
             过滤 = 床还在且两半完整、没被占用、不在 protected_labels 内、
                    周围（水平 8 格、垂直 5 格）没有敌对生物 ← 原版规则
                    夜休还要求：有往返路线（M10 往返纪律）
             有 target 时只在该床区里选；先由 M10 走到床区附近
             排序 = 路径代价
4 没有可用床
   a 背包里有床   → M2 选放置工位（两格可替换、下方有支撑、站位能看见床头、不压到自己）→ M3 放置
   b 能做一张床   → M4 获取 1 张床：身上、随身背包、已知容器、合成（3 块同色羊毛 + 3 块木板）；
                    羊毛不够时，附近有羊就剪毛（有剪刀或能做一把），否则按 M7 默认授权打野生羊取羊毛；整个差事有预算
   c 都不行       → 结束，blocker = NEED_ITEM，写明缺什么（"没有床；做床还缺 2 块羊毛，附近没有羊"）
                    夜里露天弄不到床时的自保（挖三填一）由 M6 负责，不属于本能力
5 去床边     M2 Approach，动作类型"睡床"：同时满足服务端床距离盒、交互距离和视线
             遮挡、够不着由 M2 内部换工位；床在途中消失 → 回到 3 重新选（有次数上限）
6 上床       M3 NativeAct，确认条件 = 角色正在睡
             确认窗口内日期前进 → 一觉睡到天亮，判成功
             被拒绝时读服务端提示语：
               有怪物在附近 → 威胁评估（M6）：打得过且授权 combat ≠ defend → 先清怪再睡；
                              否则带床换地方：床是自己放的或不属于任何玩家 → 收起床，
                              到附近没有怪的地方放下再睡（M2 选放置工位时避开威胁）；收不了就回到 3 换床
               床被占用     → 回到 3 换床
               只能在夜里睡 → 回到 2
               太远或被挡   → 交给 M2 换一次工位
7 完成
   公开能力       躺下即完成（保持现在的语义）
   夜休差事       等自然醒（醒来的实体包和时间包不在同一刻到达，留 200 刻同步窗口）
                  → 收回自己放下的床（放在记住的"家"区域里的不收）→ 沿往返路线回到工位 → 结清，主任务继续
```

**组合的模型**：M2（选放置位、靠近床）、M3（放床、收床、上床）、M4（做床、取羊毛）、M6（夜休作为 COMFORT 需求，只在主任务报 FREE 时插入；威胁评估）、M7（受保护标签、战斗与动物授权）、M8（尝试与回执）、M9（记忆中的床）、M10（床区出行、往返纪律）。

**本能力特有的部分**只剩：`BedChooser`、睡觉的确认条件和提示语映射、夜休的"回工位"收尾。

## 4 契约

参数：无（`goal.parameters` 为空对象）。`target` 允许 `here`、`position`、`landmark`、`seen`（07 第 4 节），含义是"在这片床区里睡"或"睡这张床"。可选的 `mandate` 按 M7 处理。

契约正文（新，替代原来的 1312 字符）：

> 找一张能用的床躺下，躺下即完成，不保证睡到天亮。附近没有床时，会放下背包里的床，或者现做一张（羊毛不够会去剪羊毛或打野羊）。床边有怪时，打得过就清掉，打不过就带床换个地方。白天不会干等：会先把今晚的床备好，然后报告"现在睡不了"，天黑后夜间自动休息会自己去睡。在下界或末地会直接结束，因为床会爆炸。target 用来指定在哪片床区睡，或指定一张看到的床。

本能力特有的回执字段：

| 字段 | 含义 |
| --- | --- |
| `entered_sleep` | 确认躺下了 |
| `bed_source` | `world`（原有的床）、`carried`（放下了自带的床）、`crafted`（现做的床） |
| `bed_ready_for_tonight` | 白天被叫去睡时，今晚的床是否已备好 |
| `relocated_from_threat` | 因为床边有怪且打不过，带床换了地方 |
| `night_skipped_by_sleep` | 确认窗口内一觉睡到了天亮 |
| `sleep_completed_externally` | 夜休去床途中夜晚被别人跳过 |

其余字段遵循 M8 的统一回执。删除 `used_carried_bed_fallback`、`village_bed_fallback_reason`，这两项信息改由 `bed_source` 和 `attempts[]` 表达。

## 6 行为变化清单（拍板用）

| # | 场景 | 之前 | 之后 |
| --- | --- | --- | --- |
| 1 | 白天让它去睡 | 提问"等 / 跳过 / 取消"，答"等"之后原地干等到天黑 | 不干等：先备好今晚的床（没有就趁白天弄一张），报告"现在睡不了，约 N 分钟后可睡"，结束；天黑后夜间自动休息会在干活间隙自己去睡 |
| 2 | 附近和背包都没床 | 提问"先去弄张床" | 现做一张：先用身上、随身背包和已知箱子里的材料，羊毛不够就剪羊毛或打野生羊（有预算）；做不了就直接结束并写明缺什么 |
| 3 | 床被墙挡住或够不着 | 睡觉专用换位一次，再回退到自带床 | M2 按候选工位依次尝试；不行换别的床；再不行放自带床 |
| 4 | 床边有怪 | 公开睡觉要点下去被拒才知道；夜休会避开这张床 | 两边一致，先做威胁评估：打得过且愿意打（`mandate.combat` 不是 `defend`）就清怪再睡；否则把床收起来（自己放的或不属于任何玩家的床），到没有怪的地方放下再睡；收不了就换别的床 |
| 5 | 床被占用 | 公开睡觉不检查 | 统一排除 |
| 6 | 在下界、末地让它睡 | 提问 | 直接结束（WORLD_RULE），回执说明原因 |
| 7 | 床区坐标的高度不对 | 拒绝前往并提问 | 先走到那一列附近，到场再找床 |
| 8 | 夜休会打断哪些任务 | 只打断施工、取物、合成、烹饪（写死的名单） | 打断任何在步骤间隙报 FREE 的任务；战斗、跟随、钓鱼、等待从不报 FREE，所以这几类的效果不变；以后新增能力不用再登记名单 |
| 9 | 夜休时附近没有床 | 不睡，接着干活 | 放下自带的床或现做一张去睡，醒后收回（放在记住的"家"区域里的不收） |
| 10 | 回执 | `used_carried_bed_fallback`、`village_bed_fallback_reason` | `bed_source` + `attempts[]` |
| 11 | 被埋时到了夜里 | 夜休专门判断不睡 | 由 M6 保证：先自救，自救完成后再考虑睡觉 |
| 12 | 夜里露天、弄不到床、怪多又打不过 | 无专门处理 | 极端情况由 M6 处理：挖三填一，把自己封在坑里熬到天亮或威胁解除 |

## 9 验收

**离线场景测试**（不使用 `Unsafe`）：

1. `BedChooser`：床已消失的旧记忆被排除；被占用、受保护、旁边有怪的床被排除；指定床区时只在区内选；按路径代价排序。
2. 放置工位：两格可替换、有支撑；站位看不见床头时换候选；不压到自己。
3. 第 2 步：白天被叫去睡 → 有床时直接以 partial 结束并报告可睡时间；没床时先备床再结束；雷暴天随时可睡；夜休去床途中夜晚被跳过 → 差事结清。
4. 第 6 步：确认窗口内日期前进 → 成功；没有日期前进的拒绝 → 失败，并带上提示语；四种提示语分别走到正确的分支。
5. 夜休：只在主任务报 FREE 时插入；往返路线不通的床不选（高柱场景）；睡不成也回到工位。
6. 床边有怪：打得过 → 清怪；打不过 → 收床换地方；收不了 → 换床。

**实机验收**（追加到冒烟清单）：

1. 中午让它去睡 → 不干等：确认有床（没有就做一张）后报告"现在睡不了"，接着干别的；天黑后自己去睡下。
2. 村庄里，床在墙后 → 绕到能看见床头的位置睡下。
3. 附近没床、背包没床、身上只有木板，旁边有羊 → 剪羊毛或打羊，做一张床，放下，睡下。
4. 在下界让它睡 → 立即结束，回执说明床会爆炸。
5. 床边站着一只僵尸（打得过）→ 清掉再睡；床边站着三只骷髅和一只苦力怕（打不过）→ 收起床，换地方睡。
6. 夜里在野外，没床、没羊、周围怪很多 → 挖三填一熬到天亮。
7. 在高柱顶上施工到夜里 → 夜休不选需要从柱顶跳下才能到的床；睡醒后回到柱顶继续施工。
8. 被埋在沙子里时到了夜里 → 先挖出来，再考虑睡觉。
9. 多人服务器上，夜休去床途中另一位玩家先睡过了这一夜 → 差事结清，回去干活。
