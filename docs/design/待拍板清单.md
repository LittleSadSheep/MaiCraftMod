## 五、所有者授权"怎么合理怎么来"后定下的事项

| 事项 | 定下的做法 |
| --- | --- |
| 玩家按 F8 收回角色 | F8 是人的急停：直到玩家再按 F8 交回，目标下达、恢复、进世界自动接管都抢不回来；task 与 observe 如实说在玩家手上（`player_took_over`）；离开世界后重新算 |
| 许可 `survival_needs=off` | 生效：它是主任务时控制循环一个生存需求都不插（特征接口 `SurvivalNeedsOff`） |
| 生存需求与任务许可 | 自救（坠落放水、刨出、换气挖顶、挖三填一）不看主任务的 `change_blocks`，这是自保不是任务；但受保护的方块（别人的东西、记住的地盘）一律不挖 |
| 夜里极端自保 | 按规格挖三填一：先看脚下一列挖不挖得成封得住的坑，挖三格、封坑口、天亮挖开爬回；挖不成站定硬熬并说明原因 |
| 饿了趁空当吃 | 身上最小的一件普通食物能整份补进去（饱食度加它不超过 20）才趁空当吃；挑补得刚好的那件，只吃普通食物，饱食度见底在掉血才什么都吃 |
| 贴边退避 | 只在身体被放开（没有任务管身体）时退；有任务时贴边是它要的姿态；退回的落点要站得住 |
| 换气被盖住 | 水面被冰面、石头盖住时先挖开头顶那一格；挖不得就如实报受困 |
| 工作站、取箱子、采集的靠近 | 按这次任务的许可走，不另用默认档 |
| 熔炉燃料 | 由加载器回答（NeoForge 燃料数据表、Fabric 燃料登记表），认得模组燃料 |
| 静态登记点 | 装着可变状态的静态字段只准在 `ClientHooks`、Mixin 包、内嵌 Baritone 的桥；界面绘制记录改为登记在 `ClientHooks` 的实例（架构检查强制） |
| 测试方法名 | 中英文都行，同一个测试类统一一种（架构检查强制），不为统一批量改名 |
| `TerrainPermit` 的名字 | 保留：09 已登记"地形许可"，它就是这次走到被允许动多少地形，名字与含义一致，改名只添迁移成本 |
